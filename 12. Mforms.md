# Django ModelForm — Complete Guide

## 1. What is a ModelForm?

A **ModelForm** is a Django form that is directly connected to a **database model**.

### Advantages

* Automatically creates form fields from the model.
* Automatically validates form data.
* Can save submitted data directly to the database using `form.save()`.

### Remember

```text
Model → ModelForm → Form → Database
```

# 6. Create the Model

Open:

```text
student/models.py
```

Create the `Student` model:

```python
from django.db import models


class Student(models.Model):
    name = models.CharField(max_length=50)
    email = models.EmailField()
    age = models.IntegerField()

    def __str__(self):
        return self.name
```

## What does this do?

The model represents a **database table**.

```text
Student Model
     ↓
Database Table

name  → Column
email → Column
age   → Column
```

Each student record becomes a row in the database.

# 7. Create the ModelForm

Create:

```text
student/forms.py
```

Add:

```python
from django import forms
from .models import Student


class StudentForm(forms.ModelForm):
    class Meta:
        model = Student
        fields = '__all__'
```

## Important

### `model`

Connects the form to the `Student` model:

```python
model = Student
```

### `fields`

Includes all model fields in the form:

```python
fields = '__all__'
```

You can also select specific fields:

```python
fields = ['name', 'email']
```

### ModelForm automatically provides

* Form fields
* Basic validation
* Model-based validation
* `save()` method

# 8. Create the View

Open:

```text
student/views.py
```

Add:

```python
from django.shortcuts import render
from .forms import StudentForm


def student_view(request):
    if request.method == "POST":
        form = StudentForm(request.POST)

        if form.is_valid():
            form.save()
            return render(request, 'success.html')

    else:
        form = StudentForm()

    return render(request, 'student.html', {'form': form})
```

## How the View Works

### GET Request

When the user opens the page:

```text
Browser
   ↓
GET Request
   ↓
StudentForm()
   ↓
Display Empty Form
```

### POST Request

When the user submits the form:

```text
Browser
   ↓
POST Request
   ↓
StudentForm(request.POST)
   ↓
form.is_valid()
   ↓
form.save()
   ↓
Database
```

# 17. What Happens When the User Submits?

Suppose the user enters:

```text
Name  : Rahul
Email : rahul@gmail.com
Age   : 21
```

Then:

```text
1. User fills the form
          ↓
2. Form sends POST request
          ↓
3. View receives request
          ↓
4. ModelForm receives request.POST
          ↓
5. form.is_valid()
          ↓
6. form.save()
          ↓
7. Data stored in database
          ↓
8. Success page displayed
```

# 19. `forms.Form` vs `forms.ModelForm`

| `forms.Form`                             | `forms.ModelForm`                     |
| ---------------------------------------- | ------------------------------------- |
| Not directly connected to a model        | Connected to a model                  |
| Fields are defined manually              | Fields can be generated automatically |
| No built-in model `save()`               | Has `save()`                          |
| Database saving must be handled manually | Can save directly to database         |

## Normal Form Example

```python
from django import forms


class StudentForm(forms.Form):
    name = forms.CharField()
    email = forms.EmailField()
```

## ModelForm Example

```python
from django import forms
from .models import Student


class StudentForm(forms.ModelForm):
    class Meta:
        model = Student
        fields = '__all__'
```
