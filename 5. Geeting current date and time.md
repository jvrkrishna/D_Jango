# Django Project No. 0004 — DateTimeProject

## 🎯 Project Objective

In this project, we will learn how to:

- Get the current date and time in Django
- Use Python's `datetime` module
- Display date and time in a web page
- Create a simple live clock using JavaScript

---

```cmd
cd Desktop
```

# Django Project Setup

## 📌 Step 1: Create the Django Project

```bash
django-admin startproject DateTimeProject
```

## 📌 Step 2: Enter into the Project

```bash
cd DateTimeProject
```

## 📌 Step 3: Create the Application

```bash
py manage.py startapp DateTimeApp
```

## 📌 Step 4: Install the Application in Settings

### `DateTimeProject/settings.py`

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'DateTimeApp',
]
```

## 📌 Step 5: Define the View Function

### `DateTimeApp/views.py`

```python
from django.shortcuts import HttpResponse

def date_time_view(request):

    return HttpResponse("""
        <h1>Current Date and Time</h1>

        <h2 id="time"></h2>

        <script>
            setInterval(function() {
                document.getElementById("time").innerHTML = new Date();
            }, 1000);
        </script>
    """)
    """

    return HttpResponse(data)
```

## 📌 Step 6: Configure URL Pattern

### `DateTimeProject/urls.py`

```python
from django.contrib import admin
from django.urls import path
from DateTimeApp import views

urlpatterns = [
    path('admin/', admin.site.urls),
    path('get_date_time/', views.date_time_view),
]
```

## 📌 Step 7: Run the Server and Test

### Start server:

```bash
py manage.py runserver
```

### Visit in browser:

```text
http://127.0.0.1:8000/get_date_time/
```
