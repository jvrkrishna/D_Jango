## 🎯 Project Objective

In this project, we will learn how to:

- Get the current date and time in Django
- Use Python's `datetime` module
- Display date and time in a web page

## 📌 Step 5: Define the View Function

### `DateTimeApp/views.py`

```python
from django.shortcuts import HttpResponse
import datetime

def date_time_view(request):

    dt = datetime.datetime.now()

    today_date = dt.strftime("%d/%m/%Y")
    current_time = dt.strftime("%H:%M:%S")

    data = f"""
    <html>
        <head>
            <title>Date and Time</title>

            <style>
                body {{
                    font-family: Arial, sans-serif;
                    background-color: #f2f2f2;
                    text-align: center;
                    padding-top: 100px;
                }}

                .container {{
                    background-color: white;
                    width: 400px;
                    margin: auto;
                    padding: 30px;
                    border-radius: 10px;
                    box-shadow: 0 0 10px gray;
                }}

                h1 {{
                    color: #0066cc;
                }}

                #time {{
                    font-size: 30px;
                    font-weight: bold;
                }}

                #date {{
                    font-size: 20px;
                }}
            </style>
        </head>

        <body>

            <div class="container">

                <h1>Current Date & Time</h1>

                <p id="date">
                    Date: {today_date}
                </p>

                <p id="time">
                    Time: {current_time}
                </p>

            </div>

            <script>

                function updateDateTime() {{

                    const now = new Date();

                    const day = String(now.getDate()).padStart(2, '0');
                    const month = String(now.getMonth() + 1).padStart(2, '0');
                    const year = now.getFullYear();

                    const hours = String(now.getHours()).padStart(2, '0');
                    const minutes = String(now.getMinutes()).padStart(2, '0');
                    const seconds = String(now.getSeconds()).padStart(2, '0');

                    document.getElementById("date").innerHTML =
                        "Date: " + day + "/" + month + "/" + year;

                    document.getElementById("time").innerHTML =
                        "Time: " + hours + ":" + minutes + ":" + seconds;
                }}

                setInterval(updateDateTime, 1000);

                updateDateTime();

            </script>

        </body>
    </html>
    """

    return HttpResponse(data)
```

## 📌 Step 6: Configure URL Pattern

# 🔑 Note

Python:

```python
datetime.datetime.now()
```

gets the current date and time when the page is loaded.

JavaScript:

```javascript
setInterval(updateDateTime, 1000);
```

updates the displayed time every **1 second**, making the clock live.
