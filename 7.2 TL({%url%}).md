# 1️⃣ `{% url %}` Template Tag

## 🎯 Purpose

The `{% url %}` tag generates a URL using the URL pattern's name.

Basic syntax:

```django
{% url 'url_name' %}
```

Our URL name is:

```text
student
```

Therefore:

```django
{% url 'student' %}
```

will generate the URL for:

```text
/App1/student/
```

---

# 🧠 Why Use `{% url %}`?

We could write:

```html
<a href="/App1/student/">
    Student
</a>
```

But this directly writes the URL.

Instead, we can write:

```html
<a href="{% url 'student' %}">
    Student
</a>
```

Django finds the URL whose name is:

```text
student
```

and generates the correct URL.

---

# 📊 Simple Flow

```text
{% url 'student' %}
        ↓
Django searches urls.py
        ↓
Finds name='student'
        ↓
Finds URL:
student/
        ↓
Project prefix:
App1/
        ↓
Final URL:
/App1/student/
```

Open:

```text

```

Add:

```html
<!DOCTYPE html>

</head>

    <h2>Name: {{ name }}</h2>

    <h2>Course: {{ course }}</h2>

    <hr>

    <a href="{% url 'student' %}">
        Student Page
    </a>

</body>

</html>
```

---

# 📌 Why Is This Useful?

Suppose today our URL is:

```python
path(
    'student/',
    views.student,
    name='student'
)
```

The template uses:

```django
{% url 'student' %}
```

Later, we change the URL path to:

```python
path(
    'student-profile/',
    views.student,
    name='student'
)
```

The template can still use:

```django
{% url 'student' %}
```

So we don't need to manually change the URL in the template.
