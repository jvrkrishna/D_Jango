# Django Project No. 0003 — HIETECH

## 🎯 Project Objective

In this project, we will learn how to:

- Create multiple Django applications inside one project
- Register multiple applications in `settings.py`
- Create views in different applications
- Import views from multiple applications using aliases
- Connect multiple application views with different URLs
- Run and test all application URLs

The Django project name is **HIETECH**.

The applications are:

```text
Students
Fees
Courses
```

The URLs are:

```text
/students/view1/
/students/view2/
/fees/
/courses/
```

## 📌 Step 3: Create Django Applications

```bash
py manage.py startapp Students

py manage.py startapp Fees

py manage.py startapp Courses
```

Add them to `INSTALLED_APPS` inside `HIETECH/settings.py`:

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',

    'Fees',
    'Courses',
]
```

## 📌 Step 4: Define View Functions for Each App

### `Students/views.py`

```python
from django.shortcuts import HttpResponse

def student_view1(request):
    return HttpResponse('<h1>Hello, you are in the Students section (view1)</h1>')

def student_view2(request):
    return HttpResponse('<h1>Hello, you are in the Students section (view2)</h1>')
```

### `Fees/views.py`

```python
from django.shortcuts import HttpResponse

def fees_view(request):
    return HttpResponse('<h1>Hello, you are in the Fees section</h1>')
```

### `Courses/views.py`

```python
from django.shortcuts import HttpResponse

def course_view(request):
    return HttpResponse('<h1>Hello, you are in the Courses section</h1>')
```

## 📌 Step 5: Define URL Patterns in project level

### `HIETECH/urls.py`

```python
from django.contrib import admin
from django.urls import path
from Students import views as v1
from Fees import views as v2
from Courses import views as v3

urlpatterns = [
    path('admin/', admin.site.urls),

    # Students App URLs
    path('students/view1/', v1.student_view1),
    path('students/view2/', v1.student_view2),

    # Fees App URL
    path('fees/', v2.fees_view),

    # Courses App URL
    path('courses/', v3.course_view),
]
```

### 🔑 Note:

We use `as v1`, `as v2`, and `as v3` while importing views because each app has a `views.py` file.

```python
from Students import views as v1
from Fees import views as v2
from Courses import views as v3
```

Then we can access the views using:

```text
v1 → Students views

v2 → Fees views

v3 → Courses views
```

or else use app-level urls.py
# Course urls.py
```text
from django.urls import path
from .views import course_view

urlpatterns = [
    path('', course_view),
]
```

# Fees urls.py
```text
from django.urls import path
from .views import fees_view

urlpatterns = [
    path('', fees_view),
]
```

# Students urls.py
```text
from django.urls import path
from .views import student_view1,student_view2

urlpatterns = [
    path('view1/', student_view1),
    path('view2/', student_view2),
]
```

#Now project-level urls.py include
```text
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('courses/', include('Courses.urls')),
    path('fees/', include('Fees.urls')),
    path('students/', include('Students.urls')),
]
```
