# Django Project No. 0009 — Bootstrap Menu Bar with `{% url %}`

## 🎯 Project Name

**Creating a Bootstrap Menu Bar Using Django `{% url %}`**

---

# 🎯 Project Objective

In this project, we will learn how to create a simple website menu bar using **Bootstrap** and Django's:

```django
{% url %}
```

We will learn:

- What is a Bootstrap navbar?
- Where the Bootstrap code comes from
- How to include Bootstrap CSS and JavaScript
- How to create menu items
- How to give names to URL patterns
- How to use `{% url %}` inside Bootstrap menu links
- Why `{% url %}` is useful in real Django websites

> **Important:**  
> Bootstrap provides the **design and responsive behavior** of the menu.  
> Django's `{% url %}` tag generates the **correct URL** for each menu item.

---

# 🖼️ How the Website Works

```text
Browser
   ↓

Template
   ↓
```

# 🌐 Where Does Bootstrap Come From?

We are using **Bootstrap 5.3** from the official Bootstrap CDN example.

Bootstrap provides ready-made CSS classes and JavaScript components so we do not have to create the complete navbar design ourselves.

The official Bootstrap documentation provides CDN links for Bootstrap CSS and JavaScript. citeturn0search0turn0search2

## Bootstrap CSS Location

We add this inside the `<head>` section:

```html
<link
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
    rel="stylesheet"
    integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB"
    crossorigin="anonymous">
```

# 📌 Bootstrap JavaScript Location

For the responsive mobile menu button, we also include Bootstrap's JavaScript bundle before `</body>`:

```html

    src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"
    integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI"
```

# 📌 Step 7: Create Application-Level `urls.py`

Create:

```text
App1/urls.py
```

Add:

```python
from django.urls import path
from . import views


urlpatterns = [

    path(
        '',
        views.home,
        name='home'
    ),

    path(
        'about/',
        views.home,
        name='about'
    ),

    path(
        'courses/',
        views.home,
        name='courses'
    ),

]
```

# 📊 URL Names

| URL Path | URL Name | View |
|---|---|---|
| `/App1/` | `home` | `home` |
| `/App1/about/` | `about` | `home` |
| `/App1/courses/` | `courses` | `home` |

Remember:

```text
URL path → where the browser goes

URL name → name used by {% url %}
```

# 🔥 Why `{% url %}` Is Useful in a Menu Bar

Imagine your website has:

```text
Home
About
Courses
Contact
Login
Register
```

Every menu item needs a URL.

We could write:

```html
href="/App1/"
href="/App1/about/"
href="/App1/courses/"
```

But this creates a problem.

If we later change:

```text
about/
```

to:

```text
about-us/
```

we would have to find and change the URL everywhere.

Instead, we use:

```django
{% url 'about' %}
```

Now Django handles the URL generation.

---

# 📊 Without `{% url %}`

```html
<a href="/App1/">
    Home
</a>

<a href="/App1/about/">
    About
</a>

<a href="/App1/courses/">
    Courses
</a>
```

The URLs are written manually.

---

# 📊 With `{% url %}`

```html
<a href="{% url 'home' %}">
    Home
</a>

<a href="{% url 'about' %}">
    About
</a>

<a href="{% url 'courses' %}">
    Courses
</a>
```

Django generates the URLs.

---

# ⭐ Main Advantage

Think of URL names as **nicknames**.

```text
Actual URL                Nickname

/App1/                    home

/App1/about/              about

/App1/courses/            courses
```

Then the template uses the nickname:

```django
{% url 'home' %}
{% url 'about' %}
{% url 'courses' %}
```
