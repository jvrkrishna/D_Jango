# Django Project No. 0009 — Bootstrap Menu Bar with `{% url %}`

## 🎯 Project Name

**Creating a Bootstrap Menu Bar Using Django `{% url %}`**

---

# 🎯 Project Objective

In this project, we will learn how to create a simple website menu bar using **Bootstrap** and Django's:

```django
{% url %}
```

We will learn:

- What is a Bootstrap navbar?
- Where the Bootstrap code comes from
- How to include Bootstrap CSS and JavaScript
- How to create menu items
- How to give names to URL patterns
- How to use `{% url %}` inside Bootstrap menu links
- Why `{% url %}` is useful in real Django websites

> **Important:**  
> Bootstrap provides the **design and responsive behavior** of the menu.  
> Django's `{% url %}` tag generates the **correct URL** for each menu item.

# 🧠 Important Point

We have only **one view**:

```python
views.home
```

But we have three URL patterns:

```text
home
about
courses
```

Each URL pattern has a different **name**:

```python
name='home'
name='about'
name='courses'
```

These names will be used by:

```django
{% url %}
```

---

# 📊 URL Names

| URL Path | URL Name | View |
|---|---|---|
| `/App1/` | `home` | `home` |
| `/App1/about/` | `about` | `home` |
| `/App1/courses/` | `courses` | `home` |

Remember:

```text
URL path → where the browser goes

URL name → name used by {% url %}
```

# 🔥 Why `{% url %}` Is Useful in a Menu Bar

Imagine your website has:

```text
Home
About
Courses
Contact
Login
Register
```

Every menu item needs a URL.

We could write:

```html
href="/App1/"
href="/App1/about/"
href="/App1/courses/"
```

But this creates a problem.

If we later change:

```text
about/
```

to:

```text
about-us/
```

we would have to find and change the URL everywhere.

Instead, we use:

```django
{% url 'about' %}
```

Now Django handles the URL generation.

---

# 📊 Without `{% url %}`

```html
<a href="/App1/">
    Home
</a>

<a href="/App1/about/">
    About
</a>

<a href="/App1/courses/">
    Courses
</a>
```

The URLs are written manually.

---

# 📊 With `{% url %}`

```html
<a href="{% url 'home' %}">
    Home
</a>

<a href="{% url 'about' %}">
    About
</a>

<a href="{% url 'courses' %}">
    Courses
</a>
```

Django generates the URLs.

---

# ⭐ Main Advantage

Think of URL names as **nicknames**.

```text
Actual URL                Nickname

/App1/                    home

/App1/about/              about

/App1/courses/            courses
```

Then the template uses the nickname:

```django
{% url 'home' %}
{% url 'about' %}
{% url 'courses' %}
```

# 🧠 Bootstrap Classes Used

| Bootstrap Class | Purpose |
|---|---|
| `navbar` | Creates navbar |
| `navbar-expand-lg` | Navbar expands on large screens |
| `bg-primary` | Gives primary background |
| `container` | Controls content width |
| `navbar-brand` | Website/project name |
| `navbar-toggler` | Mobile menu button |

# 🎯 Final Concept

A Bootstrap menu provides the **look and responsive behavior**.

Django's `{% url %}` provides the **correct URL**.

The important pattern is:

## `urls.py`

```python
path(
    'about/',
    views.home,
    name='about'
)
```

## Template

```django
<a href="{% url 'about' %}">
    About
</a>
```

So remember:

```text
Bootstrap
   ↓
Design the menu

Django URL name
   ↓
Give the URL a nickname

{% url 'name' %}
   ↓
Generate the correct link
```

> **Student Rule to Remember:**
>
> **Bootstrap makes the menu beautiful. Django `{% url %}` makes the menu links dynamic and maintainable.**
