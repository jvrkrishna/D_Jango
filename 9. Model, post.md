# 🧠 What is a Model in Django?

A **model** is a Python class that represents a database table.

Simple meaning:

> **A Django model is a blueprint for a database table.**

For example:

```text
Python Model
     ↓
Database Table
```

Each attribute in the model represents a field (column) in the database table.

---

# 📊 Simple Example

Suppose we create a `Post` model:

```python
class Post(models.Model):

    title = models.CharField(max_length=150)

    description = models.TextField()

    author = models.CharField(max_length=50)
```

Django can create a database table based on this model.

Conceptually:

```text
Post Model
     ↓
blog_post Table
```

The fields become columns:

```text
title
description
author
```

---

# 🧠 What is ORM?

Django provides an **ORM (Object-Relational Mapper)**.

ORM allows us to interact with the database using Python code instead of writing SQL queries manually.

Simple flow:

```text
Python Code
     ↓
Django ORM
     ↓
SQL Query
     ↓
Database
```

So we can work with Django models using Python.

# 📌 Step 6: Create the Model

Open:

```text
Sample_Project/blog/models.py
```

Add:

```python
from django.db import models
from datetime import datetime


class Post(models.Model):

    title = models.CharField(max_length=150)

    description = models.TextField()

    author = models.CharField(max_length=50)

    created_at = models.DateTimeField(
        default=datetime.now
    )

    is_published = models.BooleanField(
        default=False
    )

    def __str__(self):

        return self.title
```

---

| Command | Purpose |
|---|---|


# 📌 Step 10: Register the Model in Admin

Open:

```text
Sample_Project/blog/admin.py
```

Add:

```python
from django.contrib import admin
from .models import Post


class PostAdmin(admin.ModelAdmin):

    list_display = (
        'id',
        'title',
        'author',
        'created_at'
    )

    list_display_links = (
        'title',
    )

    list_filter = (
        'created_at',
        'author'
    )


admin.site.register(Post, PostAdmin)
```

---
