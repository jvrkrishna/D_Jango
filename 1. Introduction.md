# 2. What Is a Website?

A website is a collection of web pages that users access through a web
browser.

Examples:

-   College website
-   Company website
-   Wikipedia
-   News website
-   Documentation website

A simple website might contain:

``` text
Home
About
Courses
Contact
```

------------------------------------------------------------------------

# 3. What Is a Web Application?

A web application is software that users interact with through a web
browser.

Unlike a simple informational website, a web application usually:

-   Accepts user input
-   Stores data
-   Performs business logic
-   Authenticates users
-   Communicates with databases
-   Performs actions based on users' requests

## CampusQuest is a Web Application

For example:

``` text
Register
Login
Solve Challenge
Submit Answer
Earn Points
View Leaderboard
Edit Profile
```

Therefore:

> **CampusQuest is a web application, not just a collection of HTML
> pages.**

------------------------------------------------------------------------

# 4. Website vs Web Application

| Website | Web Application |
|---|---|
| Mostly provides information | Provides interactive functionality |
| Mostly read-only | Users create and modify data |
| Simpler backend | More complex backend |
| Example: College information site | Example: CampusQuest |
| Usually fewer user interactions | Authentication, forms, dashboards, CRUD, etc. |

# 7. What Happens When We Open a Website?

Suppose the student opens:

``` text
https://campusquest.com/challenges/
```

The simplified process is:

``` text
1. User enters URL
        |
        v
2. Browser creates request
        |
        v
3. Request travels to server
        |
        v
4. Server processes request
        |
        v
5. Server may communicate with database
        |
        v
6. Server creates response
        |
        v
7. Browser receives response
        |
        v
8. Browser displays the page
```

This request/response cycle is fundamental to web development.

------------------------------------------------------------------------

# 8. What Is a Request?

A request is a message sent by the client to the server asking it to
perform an operation or return information.

Example:

``` text
GET /challenges/
```

This can be understood as:

> "Server, please give me the challenges page."

------------------------------------------------------------------------

# 9. What Is a Response?

A response is the message returned by the server to the client.

For example:

``` text
HTTP 200 OK
```

The response may contain:

-   HTML
-   JSON
-   Images
-   Files
-   Error information

Simplified flow:

``` text
Browser

   GET /challenges/
          |
          v
       Django
          |
          v
      Database
          |
          v
       Django
          |
          v
   HTML Response
          |
          v
       Browser
```

------------------------------------------------------------------------

# 10. What Is HTTP?

HTTP stands for:

> **HyperText Transfer Protocol**

HTTP is one of the fundamental protocols used for communication between
clients and web servers.

Simplified:

``` text
Client
  |
  | HTTP Request
  v
Server
  |
  | HTTP Response
  v
Client
```

------------------------------------------------------------------------

# 11. HTTP Methods

HTTP provides different methods for different types of operations.

  Method   Purpose
  -------- ------------------------
  GET      Retrieve data
  POST     Create/send data
  PUT      Completely update data
  PATCH    Partially update data
  DELETE   Delete data

## CampusQuest Examples

``` text

→ Show challenges

POST
→ Submit a challenge

PUT
→ Update complete profile

PATCH
→ Update part of a profile

DELETE
→ Delete a challenge
```

We will study these in much more detail when we learn Django REST
Framework.

# 14. What Is a Framework?

Imagine building a house.

You could create everything from scratch:

-   Bricks
-   Cement
-   Doors
-   Windows
-   Electrical system
-   Plumbing
-   Structure

Or you could use an established structure and focus on building the
actual application.

A software framework provides:

-   Structure
-   Tools
-   Conventions
-   Reusable components
-   Common functionality

This allows developers to build applications faster and more
consistently.

# 15. What Is Django?

 |

 |
 +-- Security
 |

 |

 |

 |

Django lets developers focus more on application/business requirements
instead of repeatedly building basic infrastructure.

# 17. Major Django Features

  Feature          Purpose
  ---------------- ---------------------------------
  URL Routing      Connect URLs to views
  Views            Process requests
  Templates        Generate HTML
  Models           Define application data

# 27. Day 1 Important Definitions

## What is a Web Application?

A web application is software that users interact with through a web
browser.

## What is Frontend?

The part of an application that users see and interact with.

## What is Backend?

The server-side part responsible for processing requests, business
logic, database operations, authentication, security, and other
application functionality.

## What is a Client?

A program or device that sends requests to a server.

## What is a Server?

A system that receives requests, processes them, and returns responses.

## What is a Request?

A message sent from a client to a server.

## What is a Response?

A message sent from a server back to a client.

## What is HTTP?

HyperText Transfer Protocol, commonly used for communication between web
clients and servers.

## What is a Database?

A system used to persistently store and manage application data.

## What is a Framework?

A structured collection of tools, conventions, and reusable
functionality for building software applications.

## What is Django?

A high-level Python web framework for building web applications.

## What is MVT?

MVT stands for:

-   Model
-   View
-   Template

## What is a Model?

A representation of application data and database structure.

## What is a View?

The component that processes requests and contains application logic
needed to produce a response.

## What is a Template?

A file used to present dynamic application data, commonly as HTML.

## What is an ORM?

Object-Relational Mapping. It allows developers to interact with
relational database data through programming-language objects and
methods.

## What is an API?

An interface that allows software components or applications to
communicate.
