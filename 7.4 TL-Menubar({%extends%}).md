# Django Project No. 0010 — Django Template Language `{% extends %}`

## 🎯 Project Name

**Creating a Common Menu Bar and Footer Using `{% extends %}`**

---

# 🎯 Project Objective

In this project, we will learn:

- What is `{% extends %}`?
- What is `{% block content %}`?
- How to create one common `base.html`
- How to keep the menu bar common
- How to keep the footer common
- How to change only the middle content on each page

### Simple Definition

> **`{% extends %}` allows one HTML template to use another template as its base.**

The basic idea is:

```text
             base.html
        ┌─────────────────┐
        │    Menu Bar     │  ← Same
        ├─────────────────┤
        │                 │
        │     CONTENT     │  ← Changes
        │                 │
        ├─────────────────┤
        │     Footer      │  ← Same
        └─────────────────┘
```

# 📌 Step 5: Create Templates

Create this structure:

```text
App1/

└── templates/

    └── App1/

        ├── base.html
        ├── home.html
        └── about.html
```

Here:

```text
base.html
```

is the **parent template**.

And:

```text
home.html
about.html
```

are **child templates**.

---

Open:

```text

```

Add:

```python

def home(request):

    return render(request, 'App1/home.html')
```

# 📌 Step 9: Create the Parent Template — `base.html`

Create:

```text
App1/templates/App1/base.html
```

Add:

```html
<head><title>My Website</title></head>
<body>
<!-- ====================== -->
<!-- Common Menu Bar -->
<!-- ====================== -->
<h2>My Website</h2>
<a href="/App1/">Home</a>|<a href="/App1/about/">About</a>
<hr>

<!-- ====================== -->
<!-- Changing Content -->
<!-- ====================== -->
{% block content %}{% endblock %}
<hr>

<!-- ====================== -->
<!-- Common Footer -->
<!-- ====================== -->
<footer><p>© 2026 My Website</p></footer>
</body>
</html>
```

# 📌 Step 10: Create `home.html`

Open:

```text
App1/templates/App1/home.html
```

Add:

```django
{% extends 'App1/base.html' %}


{% block content %}

    <h1>Welcome to Home Page</h1>

    <p>This is my home page.</p>

{% endblock %}
```

# 📌 Step 11: Create `about.html`

Open:

```text
App1/templates/App1/about.html
```

Add:

```django
{% extends 'App1/base.html' %}


{% block content %}

    <h1>About Us</h1>

    <p>This is my about page.</p>

{% endblock %}
```

Notice that we did **not** write the menu and footer again.

They already exist in:

```text
base.html
```

# ⭐ Main Idea

We write common things **only once**.

### `base.html`

```text
Menu
  ↓
{% block content %}
  ↓
Footer
```

### `home.html`

```django
{% extends 'App1/base.html' %}

{% block content %}

<h1>Home Page</h1>

{% endblock %}
```

### `about.html`

```django
{% extends 'App1/base.html' %}

{% block content %}

<h1>About Page</h1>

{% endblock %}
```
