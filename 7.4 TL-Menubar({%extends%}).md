# Django Project No. 0010 — Django Template Language `{% extends %}`

## 🎯 Project Name

**Creating a Common Menu Bar and Footer Using `{% extends %}`**

---

# 🎯 Project Objective

In this project, we will learn:

- What is `{% extends %}`?
- What is `{% block content %}`?
- How to create one common `base.html`
- How to keep the menu bar common
- How to keep the footer common
- How to change only the middle content on each page

### Simple Definition

> **`{% extends %}` allows one HTML template to use another template as its base.**

The basic idea is:

```text
             base.html
        ┌─────────────────┐
        │    Menu Bar     │  ← Same
        ├─────────────────┤
        │                 │
        │     CONTENT     │  ← Changes
        │                 │
        ├─────────────────┤
        │     Footer      │  ← Same
        └─────────────────┘
```

# 🧠 Understand `base.html`

Our `base.html` contains:

```text
┌───────────────────────────┐
│       My Website          │
│     Home | About          │
├───────────────────────────┤
│                           │
│   {% block content %}     │
│                           │
│   Changing Content        │
│                           │
│   {% endblock %}          │
│                           │
├───────────────────────────┤
│   © 2026 My Website       │
└───────────────────────────┘
```

The menu is common.

The footer is common.

Only this part changes:

```django
{% block content %}

{% endblock %}
```

# 📌 Step 10: Create `home.html`

Open:

```text
App1/templates/App1/home.html
```

Add:

```django
{% extends 'App1/base.html' %}


{% block content %}

    <h1>Welcome to Home Page</h1>

    <p>This is my home page.</p>

{% endblock %}
```

---

# 🧠 What Does `{% extends %}` Mean?

This:

```django
{% extends 'App1/base.html' %}
```

means:

> **Use `base.html` as the parent template.**

Django takes:

```text
base.html
```

and places the `home.html` content inside:

```django
{% block content %}

{% endblock %}
```

# 📌 Step 11: Create `about.html`

Notice that we did **not** write the menu and footer again.

They already exist in:

# ⭐ Main Idea

We write common things **only once**.

### `base.html`

```text
Menu
  ↓
{% block content %}
  ↓
Footer
```

### `home.html`

```django
{% extends 'App1/base.html' %}

{% block content %}

<h1>Home Page</h1>

{% endblock %}
```

### `about.html`

```django
{% extends 'App1/base.html' %}

{% block content %}

<h1>About Page</h1>

{% endblock %}
```

# 🧠 Easy Example for Students

Think about a school notebook.

Every page has:

```text
School Name
-----------------

Page Content

-----------------
School Address
```

We don't want to write the school name and address again and again.

So we create one common format:

```text
base.html
```

Then each page only changes:

```text
Page Content
```

That is what Django template inheritance does.

# 🔥 Why `{% extends %}` Is Useful

Imagine your website has:

```text
Home
About
Courses
Contact
Login
Register
```

Without `{% extends %}`:

```text
home.html
    → Menu + Content + Footer

about.html
    → Menu + Content + Footer

courses.html
    → Menu + Content + Footer

contact.html
    → Menu + Content + Footer
```

There is a lot of repeated code.

With `{% extends %}`:

```text
                  base.html
                /     |      \
               /      |       \
           Home      About    Courses
```

The menu and footer are written only once.

# 🎯 Remember These Two

## `{% extends %}`

```django
{% extends 'App1/base.html' %}
```

Means:

> **Use `base.html` as the parent template.**

---

## `{% block content %}`

In `base.html`:

```django
{% block content %}

{% endblock %}
```

Means:

> **This is the area where child pages can put their content.**

```text
{% extends %}
      ↓
Connect child template

Area that changes
```

>
> **Write common HTML in `base.html`. Use `{% extends %}` in child pages. Put page-specific HTML inside `{% block content %}`.**
