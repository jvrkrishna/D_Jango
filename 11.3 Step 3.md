# Django Forms — Form Field Options

## 1. Create the Form

### `students/forms.py`

```python
from django import forms


# Form Field Options
class StudentForm(forms.Form):

    name = forms.CharField(
        required=True,
        label="Student Name",
        initial="John",
        help_text="Enter your full name.",
        error_messages={
            "required": "Please enter your name."
        },
        widget=forms.TextInput()
    )

    dob = forms.DateField(
        required=True,
        label="Date of Birth",
        help_text="Enter your date of birth.",
        widget=forms.DateInput(
            attrs={"type": "date"}
        )
    )

    gender = forms.ChoiceField(
        required=True,
        label="Gender",
        choices=[
            ("Male", "Male"),
            ("Female", "Female"),
            ("Others", "Others"),
        ],
        help_text="Select your gender."
    )
```
