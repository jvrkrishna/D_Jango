```python
class Post(models.Model):

    title = models.CharField(
```

# 👀 Step 11: Create the View

Open:

```text
Sample_Project/myapp/views.py
```

Add:

```python
from django.shortcuts import render
from .models import Post


# Show all posts

def myapp_view(request):

    posts = Post.objects.all()

    return render(
        request,
        'myapp/myapp_home.html',
        {
            'posts': posts
        }
    )


# Show only posts by author "RK"

def rk_posts_view(request):

    posts = Post.objects.filter(
        author="RK"
    )

    return render(
        request,
        'myapp/myapp_home.html',
        {
            'posts': posts
        }
    )
```

---

# 📌 Step 13: Create the Template

Open:


Add:

```html
<!DOCTYPE html>

<html>

<head>

    <title>My Blog Posts</title>

</head>

<body>

    <h1>Blog Posts</h1>


    {% for i in posts %}

        <h3>
            {{ i.title }}
        </h3>

        <i>
            {{ i.created_at }}
        </i>

        <br>

        <b>
            By: {{ i.author }}
        </b>

        <p>
            {{ i.content }}
        </p>

        <hr>


    {% empty %}

        <p>
            No posts available.
        </p>

    {% endfor %}

</body>

</html>
```

# 🧠 Important Concept: ORM

This code:

```python
Post.objects.all()
```

is Django ORM.

We do not need to write SQL manually.

Instead of writing a SQL query such as:

```sql
SELECT * FROM blog_post;
```

we can use:

```python
Post.objects.all()
```

Django ORM handles the database query.

---

# 📊 `Post.objects.all()`

Means:

```text
Give me all Post objects.
```

---

# 📊 `Post.objects.filter()`

Means:

```text
Give me Post objects
that match this condition.
```

Example:

```python
Post.objects.filter(
    author="RK"
)
```

Means:

```text
Give me posts
where author is RK.
```

```text
myapp_view
      ↓
```

The difference is the data sent to the template.

```text
All Posts View
      ↓
All posts


RK Posts View
      ↓
Only RK posts
```

The same template displays whatever data it receives.
