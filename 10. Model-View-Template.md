## 🎯 Project Goal

In this project, we will learn the complete Django flow:

```text
Models → Views → Templates
```

We will learn how to:

- Create a Django project and application
- Create a model
- Store blog post data in the database
- Run migrations
- Register the model in Admin
- Create a superuser
- Fetch database data in a view
- Send model data to a template
- Display database data using DTL
- Filter posts by author
- Configure application-level URLs
- Create a common `base.html`
- Create app-level Create, Read, Update, Delete options
- Connect CRUD operations with the `Post` model
- Run and test the website

Open:

```text
Sample_Project/myapp/models.py
```

Add:

```python
from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    email = models.EmailField()
    phone = models.IntegerField()
    dob = models.DateField()
    gender = models.CharField(
        max_length=10,
        choices=[
            ("Male", "Male"),
            ("Female", "Female"),
            ("Other", "Other"),
        ]
    )
    address = models.TextField()
    marks = models.FloatField()
    admission_date = models.DateField()

    def __str__(self):
        return self.name
```

# Now 📚 Django App-Level --- Views, URLs & Templates

In this section, we create the **app-level Views, URLs, and Templates**
for the `myapp` application.

The application implements **CRUD operations** for the `Student` model:

-   ➕ Create Student
-   📖 Read Students
-   ✏️ Update Student
-   🗑️ Delete Student

------------------------------------------------------------------------

# 👀 Step 13: Create App-Level Views

Open:

``` text
myapp/views.py
```

Add:

``` python
from django.shortcuts import render, redirect, get_object_or_404
from .models import Student

#=======================================================
# HOME
#=======================================================
def home(request):
    return render(request, 'home.html')
#========================================================
# CREATE - ADD NEW STUDENT
#========================================================
def create(request):
    if request.method == 'POST':
        student_name = request.POST.get('name')
        student_email = request.POST.get('email')
        student_phone = request.POST.get('phone')
        student_dob = request.POST.get('dob')
        student_gender = request.POST.get('gender')
        student_address = request.POST.get('address')
        student_marks = request.POST.get('marks')
        student_admission_date = request.POST.get('admission_date')

        Student.objects.create(name=student_name,     email=student_email,phone=student_phone,     dob=student_dob,gender=student_gender,           address=student_address,marks=student_marks,
        admission_date=student_admission_date
        )
        return redirect('read')
    return render(request, 'create.html')

#========================================================
# READ - SHOW ALL STUDENTS
#========================================================
def read(request):
    all_students = Student.objects.all()
    return render(request,'read.html',{'students': all_students})


#=======================================================
# UPDATE - SHOW ALL STUDENTS
#========================================================
def updateall(request):
    all_students = Student.objects.all()
    return render(request,'updateall.html',{'students': all_students})

#========================================================
# UPDATE - EDIT ONE STUDENT
#========================================================
def update(request, student_id):
    selected_student = get_object_or_404(Student,id=student_id)

    if request.method == 'POST':
        selected_student.name = request.POST.get('name')
        selected_student.email = request.POST.get('email')
        selected_student.phone = request.POST.get('phone')
        selected_student.dob = request.POST.get('dob')
        selected_student.gender = request.POST.get('gender')
        selected_student.address = request.POST.get('address')
        selected_student.marks = request.POST.get('marks')
        selected_student.admission_date = request.POST.get('admission_date')

        selected_student.save()
        return redirect('updateall')
    return render(request,'update.html',       {'student': selected_student})


#=======================================================
# DELETE - SHOW ALL STUDENTS
#========================================================
def deleteall(request):
    all_students = Student.objects.all()
    return render(request,'deleteall.html',{'students': all_students})

#=======================================================
# DELETE - DELETE ONE STUDENT
#=======================================================
def delete(request, student_id):
    selected_student = get_object_or_404(Student,        id=student_id)

    if request.method == 'POST':
        selected_student.delete()
        return redirect('deleteall')
    return render(request,'delete.html',{'student': selected_student})
```
