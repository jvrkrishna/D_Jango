# Django Project No. 0013 — Models → Views → Templates
## 🎯 Project Goal

In this project, we will learn the complete Django flow:

```text
Models → Views → Templates
```

We will learn how to:

- Create a Django project and application
- Create a model
- Store blog post data in the database
- Run migrations
- Register the model in Admin
- Create a superuser
- Fetch database data in a view
- Send model data to a template
- Display database data using DTL
- Filter posts by author
- Configure application-level URLs
- Create a common `base.html`
- Create app-level Create, Read, Update, Delete options
- Connect CRUD operations with the `Post` model
- Run and test the website

```python
from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    email = models.EmailField()
    phone = models.IntegerField()
    dob = models.DateField()
    gender = models.CharField(
        max_length=10,
        choices=[
            ("Male", "Male"),
            ("Female", "Female"),
            ("Other", "Other"),
        ]
    )
    address = models.TextField()
    marks = models.FloatField()
    admission_date = models.DateField()

    def __str__(self):
        return self.name
```

# Now 📚 Django App-Level --- Views, URLs & Templates

In this section, we create the **app-level Views, URLs, and Templates**
for the `myapp` application.

The application implements **CRUD operations** for the `Student` model:

-   ➕ Create Student
-   📖 Read Students
-   ✏️ Update Student
-   🗑️ Delete Student

------------------------------------------------------------------------

# 👀 Step 13: Create App-Level Views

Open:

``` text
myapp/views.py
```

Add:

``` python
from django.shortcuts import render,redirect,get_object_or_404

from .models import Student

# Read/Update/delete view
def read(request, action='read'):
    all_students = Student.objects.all()
    return render(request, 'read.html', {
        'students': all_students,
        'action': action
    })

#create view
def create(request):
    if request.method == 'POST':
        name = request.POST.get('name')
        dob = request.POST.get('dob')
        gender = request.POST.get('gender')

        Student.objects.create(name=name,dob=dob,gender=gender)
        return redirect('read')
    return render(request, 'create.html')

#update record view
def update_record(request, id):
    selected_student = get_object_or_404(Student, id=id)

    if request.method == 'POST':
        selected_student.name = request.POST.get('name')
        selected_student.dob = request.POST.get('dob')
        selected_student.gender = request.POST.get('gender')

        selected_student.save()
        return redirect('read')
    return render(request, 'update_record.html', {'students': selected_student})

#Delete Record view
def delete_record(request, id):
    selected_student = get_object_or_404(Student, id=id)

    if request.method == 'POST':
        selected_student.delete()
        return redirect('read')
    return render(request, 'delete_record.html', {'students': selected_student})
```

# 🔗 Step 14: Create App-Level URLs

Open:

``` text
myapp/urls.py
```

Add:

``` python
from django.urls import path
from .views import *
urlpatterns = [
    path('read/', read, name='read'),
    path('update/', read, {'action': 'update'}, name='update'),
    path('delete/', read, {'action': 'delete'}, name='delete'),
    
    path('create/',create,name='create'),

path('update/<int:id>/', update_record, name='update_record'),
path('delete/<int:id>/', delete_record, name='delete_record'),
]
```

All templates inherit the project-level `base.html`.

We use:

``` html
{% extends 'base.html' %}
```

This reuses the common Header, Navigation, Footer, and CSS from
`base.html`.
