# Django Project No. 0002 — WelcomeProject

## 🎯 Project Objective

In this project, we will learn how to:

- Create a Django project
- Create a Django application
- Register the application in `settings.py`
- Create multiple view functions
- Connect multiple URLs with different view functions
- Send HTTP responses from Django views

The application name will be **Wishapp**.

We will create three URLs:

```text
/wish/
/wish_me/
/thank_you/
```

Each URL will display a different message.

### What is a Django Application?

A Django **project** is the complete website/system.

A Django **application** is a component inside the project that handles a particular functionality.

In our example:

```text
WelcomeProject
      ↓

      ↓
   Wishapp
      ↓
 Application
```

# Step 4: Register `Wishapp` in `settings.py`

Django does not automatically know that we created the `Wishapp` application.

We need to add the application to `INSTALLED_APPS`.

Open:

```text
WelcomeProject/WelcomeProject/settings.py
```

Find:

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
]
```

Add:

```python
'Wishapp',
```

The final code will be:

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'Wishapp',
]
```

### Why do we do this?

We are telling Django:

> **"Wishapp is one of the applications used by our project."**

After adding it to `INSTALLED_APPS`, Django recognizes the application.

# Step 5: Define View Functions

Open:

```text
WelcomeProject/Wishapp/views.py
```

Add:

```python
from django.shortcuts import render, HttpResponse

# Create your views here.

def wish_view(request):
    return HttpResponse('Welcome to Django App')

def wish_me_view(request):
    return HttpResponse('Hi Surendra Welcome to Django App')

def thank_you_view(request):
    return HttpResponse('Thank you for visit our Django App')
```

---

# What is a View?

A **view** is a Python function that receives an HTTP request and returns an HTTP response.

The basic flow is:

```text
Browser
   ↓
HTTP Request
   ↓
View Function
   ↓
HTTP Response
   ↓
Browser
```

For example:

```python
def wish_view(request):
    return HttpResponse('Welcome to Django App')
```

When this view is called, Django returns:

```text
Welcome to Django App
```

# Step 6: Define URL Patterns

Open:

```text
WelcomeProject/WelcomeProject/urls.py
```

Add:

```python
from django.contrib import admin
from django.urls import path
from Wishapp import views

urlpatterns = [
    path('admin/', admin.site.urls),
    path('wish/', views.wish_view),
    path('wish_me/', views.wish_me_view),
    path('thank_you/', views.thank_you_view),
]
```

---

# What is URL Routing?

URL routing connects a URL with a view function.

For example:

```python
path('wish/', views.wish_view)
```

means:

```text
URL
 ↓
wish/
 ↓
wish_view()
```

Similarly:

```python
path('wish_me/', views.wish_me_view)
```

means:

```text
URL
 ↓
wish_me/
 ↓
wish_me_view()
```

And:

```python
path('thank_you/', views.thank_you_view)
```

means:

```text
URL
 ↓
thank_you/
 ↓
thank_you_view()
```

# URL and View Mapping

We can easily remember the URL mappings like this:

| URL | View Function | Response |
|---|---|---|
| `/wish/` | `wish_view` | Welcome to Django App |
| `/wish_me/` | `wish_me_view` | Hi Surendra Welcome to Django App |
| `/thank_you/` | `thank_you_view` | Thank you for visit our Django App |
