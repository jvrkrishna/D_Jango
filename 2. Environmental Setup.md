# 5. What Is pip?

`pip` is Python's package installer.

Example:

```powershell
python -m pip install django
```

This tells Python's package manager to download and install Django and its dependencies.

A good habit is to use:

```powershell
python -m pip
```

instead of relying only on:

```powershell
pip
```

because it makes it clear which Python installation is being used.

---

# 6. Why Do We Need a Virtual Environment?

Suppose we have two projects:

```text
Project A
Django version A

Project B
Django version B
```

If everything is installed globally, projects can interfere with each other.

Instead:

```text
CampusQuest
   |
   +-- venv
       |
       +-- Django
       +-- DRF
       +-- psycopg
       +-- python-dotenv
```

Another project can have its own environment:

```text
AnotherProject
   |
   +-- venv
       |
       +-- Different dependencies
```

> **A virtual environment isolates a project's Python dependencies from other projects and the system Python installation.**

# 11. Understand the Command

```powershell
python -m venv venv
```

### `python`

Use Python.

### `-m`

Run a Python module.

### First `venv`

Python's built-in virtual-environment module.

### Final `venv`

The name of the environment we are creating.

So the command means:

> Use Python's built-in `venv` module to create a virtual environment named `venv`.

# 12. Activate the Virtual Environment

## PowerShell

```powershell
.\venv\Scripts\Activate.ps1
```

## Command Prompt

```cmd
venv\Scripts\activate
```

After activation:

```text
(venv) C:\Projects\CampusQuest>
```

The `(venv)` indicates that the virtual environment is active.

---

# 13. PowerShell Execution Policy Issue

Sometimes PowerShell may block the activation script.

You may see an error related to scripts being disabled.

For the current PowerShell session:

```powershell
Set-ExecutionPolicy -Scope Process RemoteSigned
```

Then:

```powershell
.\venv\Scripts\Activate.ps1
```

Alternatively, use Command Prompt:

```cmd
venv\Scripts\activate
```

# 21. What Is requirements.txt?

Suppose another developer receives the CampusQuest source code.

They need to know:

> Which Python packages does this project require?

`requirements.txt` records project dependencies.

Example:

```text
Django==...
djangorestframework==...
psycopg==...
python-dotenv==...
```

The exact versions depend on the environment used when the file was generated.

---

# 22. Create requirements.txt

Run:

```powershell
python -m pip freeze > requirements.txt
```

View it:

```powershell
Get-Content requirements.txt
```

Or open it in VS Code.

---

# 23. Why Is requirements.txt Important?

Suppose our team has:

```text
Developer A
Developer B
Developer C
```

Everyone needs the project's dependencies.

A new developer can create a virtual environment and run:

```powershell
python -m pip install -r requirements.txt
```

This helps reproduce the project's Python environment.

---

# 24. Freeze vs Install

Create the dependency list:

```powershell
python -m pip freeze > requirements.txt
```

Install dependencies from the list:

```powershell
python -m pip install -r requirements.txt
```

Remember:

```text
pip freeze
    ↓
requirements.txt
    ↓
pip install -r requirements.txt
```

# 31. `venv` vs `requirements.txt`

These are different.

## `venv`

The actual local Python environment containing installed packages.

```text
venv/
```

## `requirements.txt`

A list of dependencies needed by the project.

```text
requirements.txt
```

Simple analogy:

```text
venv
=
Actual toolbox

requirements.txt
=
List of tools required
```


# 🎤 Day 2 Interview Questions

## Q1. What is a virtual environment?

A virtual environment is an isolated Python environment used to keep a project's dependencies separate from other projects and the system Python installation.

## Q2. Why should we use a virtual environment?

It prevents dependency conflicts and makes projects easier to reproduce and maintain.

## Q3. What is pip?

pip is Python's package installer and package-management tool.

## Q4. What is requirements.txt?

A file that records the Python dependencies required by a project, often including package versions.

## Q5. How do you create a virtual environment?

```powershell
python -m venv venv
```

## Q6. How do you activate a virtual environment in Windows PowerShell?

```powershell
.\venv\Scripts\Activate.ps1
```

## Q7. How do you activate it in Command Prompt?

```cmd
venv\Scripts\activate
```

## Q8. How do you install Django?

```powershell
python -m pip install django
```

## Q9. How do you create requirements.txt?

```powershell
python -m pip freeze > requirements.txt
```

## Q10. How do you install dependencies from requirements.txt?

```powershell
python -m pip install -r requirements.txt
```

## Q11. What is the PostgreSQL driver?

A Python package that allows Python/Django applications to communicate with PostgreSQL.

## Q12. What is python-dotenv?

A Python package commonly used to load configuration values from `.env` files into environment variables.
