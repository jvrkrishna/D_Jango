# Django Project No. 0001 — `render()` with Images and Template Variables

## 1. Project Goal

In this project, we will extend **Project 0003**.

We will learn how to:

- Use `render()` with a template.
- Pass variables from `views.py` to HTML.
- Display variables using Django Template Language (DTL).
- Pass multiple parameters.
- Display an image from the `static` folder.
- Use template tags and variables together.
- Understand the complete flow from `views.py` → `render()` → template.


## 2. Create Variables in `views.py`

Open:

```text
WelcomeProject/views.py
```

Add:

```python
from django.shortcuts import render

def hello_ram(request):

    name = "RAM"
    age = 21
    course = "Django"
    city = "Visakhapatnam"

    return render(request, 'hello.html', {
        'name': name,
        'age': age,
        'course': course,
        'city': city,
    })
```

## 3. Template Variables

Open:

```text
WelcomeProject/templates/hello.html
```

Add:

```html
{% load static %}

<!DOCTYPE html>
<html>
<head>
    <title>Welcome Project</title>

    <link rel="stylesheet" href="{% static 'css/style.css' %}">
</head>

<body>

    <h1>HELLO {{ name }}</h1>

    <p>Name: {{ name }}</p>

    <p>Age: {{ age }}</p>

    <p>Course: {{ course }}</p>

    <p>City: {{ city }}</p>

</body>
</html>
```

---

## 4. Add the Image

Because the image is inside the static folder, first load the static template tag:

```django
{% load static %}
```

Then use:

```html
<img src="{% static 'images/ram.jpg' %}" alt="Ram">
```

Add it to the template.

The complete template becomes:

```html
{% load static %}

<!DOCTYPE html>
<html>
<head>
    <title>Welcome Project</title>

    <link rel="stylesheet" href="{% static 'css/style.css' %}">
</head>

<body>

    <h1>HELLO {{ name }}</h1>

    <img src="{% static 'images/ram.jpg' %}" alt="Ram">

    <p>Name: {{ name }}</p>

    <p>Age: {{ age }}</p>

    <p>Course: {{ course }}</p>

    <p>City: {{ city }}</p>

</body>
</html>
```
