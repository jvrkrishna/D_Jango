Open:

```text

```

```python
def hello_ram(request):

        'name': name,
        'age': age,

```

---

## 6. Understanding the Variables

We created four Python variables:

```python
name = "RAM"
age = 21
course = "Django"
city = "Visakhapatnam"
```

Then we pass them to the template:

```python
{
    'name': name,
    'age': age,
    'course': course,
    'city': city,
}
```

This dictionary is called the **context**.

The general pattern is:

```python
return render(request, 'template.html', context)
```

For example:

```python
return render(request, 'hello.html', {
    'name': name,
})
```

---

## 7. What Is a Context?

The context is the data that we send from Python to the HTML template.

For example:

```python
{
    'name': 'RAM',
    'age': 21,
}
```

The template receives these values.

We can then use them inside HTML.

## 9. Understanding `{{ }}`

Django Template Language uses:

```text
{{ variable }}
```

to display a variable.

For example:

```django
{{ name }}
```

If the view contains:

```python
name = "RAM"
```

the browser displays:

```text
RAM
```

Similarly:

```django
{{ age }}
```

displays:

```text
21
```

---

## 10. Python Variable → Template Variable

The view contains:

```python
name = "RAM"
```

and:

```python
{
    'name': name,
}
```

The template contains:

```django
{{ name }}
```

The flow is:

```text
Python
   ↓
name = "RAM"
   ↓
Context
   ↓
'name': name
   ↓
Template
   ↓
{{ name }}
   ↓
RAM
```

## 21. Important Template Language Syntax

Django Template Language commonly uses three important syntaxes.

### Variables

Use:

```django
{{ variable }}
```

Example:

```django
{{ name }}
```

---

### Tags

Use:

```django
{% tag %}
```

Example:

```django
{% load static %}
```

Another example:

```django
{% if age >= 18 %}
    Adult
{% endif %}
```

---

### Comments

Use:

```django
{# This is a Django template comment #}
```

The browser will not receive this comment.

## 24. Passing a List

You can also pass a Python list:

```python
students = ['RAM', 'RAHUL', 'ARUN']

return render(request, 'hello.html', {
    'students': students,
})
```

The template can access the list using a loop:

```django
{% for student in students %}
    <p>{{ student }}</p>
{% endfor %}
```

Output:

```text
RAM
RAHUL
ARUN
```

## 26. `render()` Syntax to Remember

The basic syntax is:

```python
render(request, 'template.html')
```

With variables:

```python
render(request, 'template.html', {
    'key': value,
})
```

With multiple variables:

```python
render(request, 'template.html', {
    'name': name,
    'age': age,
    'course': course,
})
```

---

## 27. `HttpResponse` vs `render()`

### `HttpResponse`

```python
from django.http import HttpResponse

def hello_ram(request):
    return HttpResponse("HELLO RAM")
```

Best for a simple direct response.

### `render()`

```python
from django.shortcuts import render

def hello_ram(request):
    return render(request, 'hello.html')
```

Best when returning an HTML template.

### `render()` with variables

```python
return render(request, 'hello.html', {
    'name': 'RAM',
})
```

Best when Python needs to send data to the HTML page.
