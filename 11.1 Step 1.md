# Django Forms --- Stage 1: Basic Student Form

## 1. Create the Django Project

Open the terminal:

``` bash
cd Desktop
mkdir forms
cd forms

py -m venv venv
venv\Scripts\activate

python -m pip install django

django-admin startproject django_forms_project
cd django_forms_project

python manage.py startapp students
```

------------------------------------------------------------------------

## 2. Register the App

Open:

``` text
django_forms_project/settings.py
```

Find `INSTALLED_APPS` and add `'students'`:

``` python
INSTALLED_APPS = [
    "students",

    "django.contrib.admin",
    "django.contrib.auth",
    "django.contrib.contenttypes",
    "django.contrib.sessions",
    "django.contrib.messages",
    "django.contrib.staticfiles",
]
```

------------------------------------------------------------------------

## 3. Create App URLs

Create this file manually:

``` text
students/urls.py
```

Add:

``` python
from django.urls import path
from . import views


urlpatterns = [
    path("", views.student_form, name="student_form"),
]
```

------------------------------------------------------------------------

## 4. Configure Project URLs

Open:

``` text
django_forms_project/urls.py
```

Use:

``` python
from django.contrib import admin
from django.urls import include, path


urlpatterns = [
    path("admin/", admin.site.urls),
    path("student/", include("students.urls")),
]
```

------------------------------------------------------------------------

## 5. Create the Form

Open:

``` text
students/forms.py
```

Add:

``` python
from django import forms


class StudentForm(forms.Form):
    name = forms.CharField()

    dob = forms.DateField()

    gender = forms.ChoiceField(
        choices=[
            ("Male", "Male"),
            ("Female", "Female"),
            ("Others", "Others"),
        ]
    )
```

------------------------------------------------------------------------

## 6. Create the View

Open:

``` text
students/views.py
```

Add:

``` python
from django.shortcuts import render
from .forms import StudentForm


def student_form(request):
    form = StudentForm()

    return render(
        request,
        "student_form.html",
        {"form": form},
    )
```

------------------------------------------------------------------------

## 7. Create the Template

Create this folder and file:

``` text
students/
└── templates/
    └── student_form.html
```

Create:

``` text
students/templates/student_form.html
```

Add:

``` html
<!DOCTYPE html>
<html>
<head>
    <title>Student Form</title>
</head>

<body>

    <h1>Student Registration</h1>

    <form method="post">

        {% csrf_token %}

        {{ form.as_p }}

        <button type="submit">
            Submit
        </button>

    </form>

</body>
</html>
```

------------------------------------------------------------------------

## 8. Run Migrations

From the directory containing `manage.py`:

``` bash
python manage.py migrate
```

------------------------------------------------------------------------

## 9. Run the Server

``` bash
python manage.py runserver
```

Open in the browser:

``` text
http://127.0.0.1:8000/student/
```

------------------------------------------------------------------------

## 10. Expected Result

The browser should display:

``` text
Student Registration

Student Name: __________________

Date of birth: _________________

Gender: [---------]

Submit
```

At this stage, the form is displayed, but the submitted data is not
processed yet.
