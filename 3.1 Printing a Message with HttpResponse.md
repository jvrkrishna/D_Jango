# Django Project No. 0001 — Printing a Message with `HttpResponse`

## 1. Project Goal

In this project, we will learn how to display a simple message directly in the browser using Django's `HttpResponse`.

The message we want to display is:

```text
HELLO RAM
```

### Important

In this project, we will **not create a separate Django app**.

We will work directly at the **Django project level** using:

- `views.py` — to create the response
- `urls.py` — to connect a URL to the view
- `HttpResponse` — to send text from Django to the browser

## 4. Create `views.py`

The default Django project does not normally contain a `views.py` file.

Create a new file:

```text
WelcomeProject/views.py
```

Add the following code:

```python
from django.http import HttpResponse

def hello_ram(request):
    return HttpResponse("HELLO RAM")
```

---

## 5. Understand `views.py`

### Import `HttpResponse`

```python
from django.http import HttpResponse
```

This imports Django's `HttpResponse` class.

We need it because we want Django to send a simple text response back to the browser.

### Create the View Function

```python
def hello_ram(request):
```

This creates a Django view function named:

```text
hello_ram
```

Django passes the browser request into the `request` parameter.

### Return the Message

```python
return HttpResponse("HELLO RAM")
```

This sends the following response to the browser:

```text
HELLO RAM
```

So the complete `views.py` is:

```python
from django.http import HttpResponse

def hello_ram(request):
    return HttpResponse("HELLO RAM")
```

## 6. Modify `urls.py`

Open:

```text
WelcomeProject/urls.py
```

Initially, it will look approximately like:

```python
from django.contrib import admin
from django.urls import path

urlpatterns = [
    path('admin/', admin.site.urls),
]
```

Import the view:

```python
from .views import hello_ram
```

Then add the URL pattern:

```python
path('hello/', hello_ram),
```

The complete `urls.py` becomes:

```python
from django.contrib import admin
from django.urls import path
from .views import hello_ram

urlpatterns = [
    path('admin/', admin.site.urls),
    path('hello/', hello_ram),
]
```

---

## 7. Understand the URL Connection

The important line is:

```python
path('hello/', hello_ram),
```

It connects:

```text
/hello/
```

to:

```text
hello_ram
```

So when the browser requests:

```text
http://127.0.0.1:8000/hello/
```

Django calls:

```python
hello_ram(request)
```

The function returns:

```python
HttpResponse("HELLO RAM")
```

The browser then displays:

```text
HELLO RAM
```

## 10. How the Request Works

The complete flow is:

```text
Browser
   |
   |  http://127.0.0.1:8000/hello/
   ↓
urls.py
   |
   |  path('hello/', hello_ram)
   ↓
views.py
   |
   |  hello_ram(request)
   ↓
HttpResponse
   |
   |  "HELLO RAM"
   ↓
Browser
   |
   ↓
HELLO RAM
```

## 11. Important Django Concept

Remember this basic Django pattern:

```python
from django.http import HttpResponse

def function_name(request):
    return HttpResponse("MESSAGE")
```

For this project:

```python
from django.http import HttpResponse

def hello_ram(request):
    return HttpResponse("HELLO RAM")
```

And connect it in `urls.py`:

```python
path('hello/', hello_ram),
```

Therefore:

```text
URL → View → HttpResponse → Browser
```
