from django.shortcuts import render


def students(request):

    student_list = [
        {
            'name': 'Rahul',
            'marks': 85
        },
        {
            'name': 'Priya',
            'marks': 45
        },
        {
            'name': 'Arun',
            'marks': 72
        }

        'students': student_list
    }

    return render(
        request,
        'App1/students.html',
        context
    )

# 🧠 What Is `context`?

The `context` is the data that we send from the view to the template.

Here:

```python
context = {
    'students': student_list
}
```

We are sending the student list to the HTML template.

The template receives:

```text
students
   ↓
Rahul  → 85
Priya  → 45
Arun   → 72
```

# 1️⃣ `{% for %}` Template Tag

## 🎯 Purpose

The `{% for %}` tag is used to **repeat HTML for every item in a list**.

Simple meaning:

> **Take one item at a time from a list and display it.**

---

## 📌 Basic Syntax

```django
{% for item in items %}

    HTML

{% endfor %}
```

---

## 📌 Example

Our view sends:

```python
students = [
    'Rahul',
    'Priya',
    'Arun'
]
```

Inside the template:

```django
{% for student in students %}

    {{ student }}

{% endfor %}
```

Django takes:

```text
Rahul
Priya
Arun
```

one by one and displays them.

---

# 🧠 Understanding the Loop

```django
{% for student in students %}
```

Here:

```text
student  → one student at a time

students → complete list
```

The loop works like:

```text
students
   ↓
Rahul
   ↓
Display Rahul

   ↓
Priya
   ↓
Display Priya

   ↓
Arun
   ↓
Display Arun
```

---

# 2️⃣ `{% if %}` Template Tag

## 🎯 Purpose

The `{% if %}` tag is used to **check a condition**.

Simple meaning:

> **If the condition is true, execute the HTML inside the `if` block.**

---

## 📌 Basic Syntax

```django
{% if condition %}

    HTML

{% endif %}
```

---

## 📌 Using `{% else %}`

```django
{% if condition %}

    HTML if TRUE

{% else %}

    HTML if FALSE

{% endif %}
```

---

# 🧠 Example

Suppose:

```text
Marks = 85
```

We write:

```django
{% if marks >= 50 %}

    <p>PASS</p>

{% else %}

    <p>FAIL</p>

{% endif %}
```

Django checks:

```text
Is 85 >= 50?
       ↓
      YES
       ↓
     PASS
```

For:

```text
Marks = 45
```

Django checks:

```text
Is 45 >= 50?
       ↓
       NO
       ↓
      FAIL
```

---

# 🔥 Combining `{% for %}` and `{% if %}`

This is the main example of this project.

Open:

```text
App1/templates/App1/students.html
```

Add:

```html
<!DOCTYPE html>

<html>

<head>

    <title>Student Results</title>

</head>

<body>

    <h1>🎓 Student Results</h1>


    {% for student in students %}

        <h2>{{ student.name }}</h2>

        <p>
            Marks: {{ student.marks }}
        </p>


        {% if student.marks >= 50 %}

            <p>✅ Result: PASS</p>

        {% else %}

            <p>❌ Result: FAIL</p>

        {% endif %}


        <hr>

    {% endfor %}

</body>

</html>
```

---

# 🧠 How This Template Works

First:

```django
{% for student in students %}
```

takes one student at a time.

Then:

```django
{{ student.name }}
```

displays the student's name.

Then:

```django
{{ student.marks }}
```

displays the marks.

Then:

```django
{% if student.marks >= 50 %}
```

checks whether the student passed.

---

# 📊 Complete Flow

```text
Student List
     ↓
{% for %}
     ↓
Take one student
     ↓
Display Name
     ↓
Display Marks
     ↓
{% if %}
   /     \
 YES      NO
  ↓        ↓
PASS      FAIL
```
