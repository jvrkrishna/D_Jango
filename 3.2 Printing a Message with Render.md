# Django Project No. 0001 — Using `render()` with Templates and Static Files

## 1. Project Goal

In this project, we will learn how to use Django's `render()` function instead of returning plain text with `HttpResponse`.

We will also learn:

- How to create a `templates` folder.
- How to create an HTML file.
- How to connect `views.py` to an HTML template.
- How to create a `static` folder.
- How to configure `templates` and `static` in `settings.py`.
- How to load CSS from the static folder.

---

## 3. Create `hello.html`

Open:

```text
WelcomeProject/templates/hello.html
```

Add:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Welcome Project</title>
</head>

<body>

    <h1>HELLO RAM</h1>

</body>
</html>
```

This is the HTML page that Django will send to the browser.

---

## 4. Configure Templates in `settings.py`

Open:

```text
WelcomeProject/settings.py
```

Find:

```python
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [],
        'APP_DIRS': True,
        ...
    },
]
```

Change:

```python
'DIRS': [],
```

to:

```python
'DIRS': [BASE_DIR / 'templates'],
```

### Why do we do this?

This tells Django:

```text
Look for HTML templates inside:

BASE_DIR / templates
```

So Django can find:

```text
templates/hello.html
```

---

## 5. Create the View Using `render()`

Open:

```text
WelcomeProject/views.py
```

Previously we used:

```python
from django.http import HttpResponse

def hello_ram(request):
    return HttpResponse("HELLO RAM")
```

Now we will use `render()`.

Change the file to:

```python
from django.shortcuts import render

def hello_ram(request):
    return render(request, 'hello.html')
```

---

## 6. Connect the View to the URL

Open:

```text
WelcomeProject/urls.py
```

Make sure it contains:

```python
from django.contrib import admin
from django.urls import path
from .views import hello_ram

urlpatterns = [
    path('admin/', admin.site.urls),
    path('hello/', hello_ram),
]
```

## 7. Test the Template

Start the server:

```cmd
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/hello/
```

```text

```

But now the message is coming from:


## 9. Create the CSS File

Open:

```text
WelcomeProject/static/css/style.css
```

Add:

```css
body {
    font-family: Arial, sans-serif;
}

h1 {
    text-align: center;
}
```

## 10. Configure Static Files in `settings.py`

Open:

```text
WelcomeProject/settings.py
```

Find:

```python
STATIC_URL = 'static/'
```

Add:

```python
STATICFILES_DIRS = [
    BASE_DIR / 'static',
]
```

## 11. Load Static Files in the Template

Now open:

```text
WelcomeProject/templates/hello.html
```

At the very top, add:

```django
{% load static %}
```

Then add the CSS file inside `<head>`:

```html
<link rel="stylesheet" href="{% static 'css/style.css' %}">
```

The complete file becomes:

```html
{% load static %}

<!DOCTYPE html>
<html>
<head>
    <title>Welcome Project</title>

    <link rel="stylesheet" href="{% static 'css/style.css' %}">
</head>

<body>

    <h1>HELLO RAM</h1>

</body>
</html>
```

---

## 12. Understand `{% load static %}`

This line:

```django
{% load static %}
```

loads Django's static template tag.

It allows us to use:

```django
{% static 'css/style.css' %}
```

---

## 13. Understand `{% static %}`

This:

```django
{% static 'css/style.css' %}
```

tells Django to generate the correct URL for:

```text
static/css/style.css
```

Instead of manually writing:

```html
<link rel="stylesheet" href="/static/css/style.css">
```

we use:

```html
<link rel="stylesheet" href="{% static 'css/style.css' %}">
```

This is the recommended Django template approach.
