# Django Project No. 0001 — Using `render()` with Templates and Static Files

## 1. Project Goal

In this project, we will learn how to use Django's `render()` function instead of returning plain text with `HttpResponse`.

We will also learn:

- How to create a `templates` folder.
- How to create an HTML file.
- How to connect `views.py` to an HTML template.
- How to create a `static` folder.
- How to configure `templates` and `static` in `settings.py`.
- How to load CSS from the static folder.

## 6. Configure Templates in `settings.py`

Open:

```text
WelcomeProject/settings.py
```

Find:

```python
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [],
        'APP_DIRS': True,
        ...
    },
]
```

Change:

```python
'DIRS': [],
```

to:

```python
'DIRS': [BASE_DIR / 'templates'],
```

So it becomes:

```python
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [BASE_DIR / 'templates'],
        'APP_DIRS': True,
        'OPTIONS': {
            'context_processors': [
                'django.template.context_processors.request',
                'django.contrib.auth.context_processors.auth',
                'django.contrib.messages.context_processors.messages',
            ],
        },
    },
]
```

### Why do we do this?

This tells Django:

```text
Look for HTML templates inside:

BASE_DIR / templates
```

So Django can find:

```text
templates/hello.html
```

## 7. Create the View Using `render()`

Open:

```text
WelcomeProject/views.py
```

Previously we used:

```python
from django.http import HttpResponse

def hello_ram(request):
    return HttpResponse("HELLO RAM")
```

Now we will use `render()`.

Change the file to:

```python
from django.shortcuts import render

def hello_ram(request):
    return render(request, 'hello.html')
```

---

## 8. Understand `render()`

The important line is:

```python
return render(request, 'hello.html')
```

The `render()` function does the work of:

```text
Find template
     ↓
Load HTML
     ↓
Create HTTP response
     ↓
Send response to browser
```

The first argument is:

```python
request
```

The second argument is:

```python
'hello.html'
```

So Django looks for:

```text
templates/hello.html
```

---

## 9. Connect the View to the URL

Open:

```text
WelcomeProject/urls.py
```

Make sure it contains:

```python
from django.contrib import admin
from django.urls import path
from .views import hello_ram

urlpatterns = [
    path('admin/', admin.site.urls),
    path('hello/', hello_ram),
]
```

Now:

```text
/hello/
```

calls:

```text
hello_ram()
```

The view then renders:

```text
hello.html
```

## 11. Understand the New Flow

Previously:

```text

   ↓

   ↓

   ↓
HttpResponse()
   ↓

```

Now:

```text

   ↓
```

## 14. Configure Static Files in `settings.py`

Open:

```text
WelcomeProject/settings.py
```

Find:

```python
STATIC_URL = 'static/'
```

Add:

```python
STATICFILES_DIRS = [
    BASE_DIR / 'static',
]
```

So the static configuration becomes:

```python
STATIC_URL = 'static/'

STATICFILES_DIRS = [
    BASE_DIR / 'static',
]
```

---

## 15. Understand `STATIC_URL`

This:

```python
STATIC_URL = 'static/'
```

defines the URL prefix used for static files.

For example:

```text
/static/css/style.css
```

---

## 16. Understand `STATICFILES_DIRS`

This:

```python
STATICFILES_DIRS = [
    BASE_DIR / 'static',
]
```

tells Django where our project-level static files are located.

In our project:

```text
BASE_DIR
   ↓
static/
   ↓
css/
   ↓
style.css
```

So Django knows to look inside:

```text
BASE_DIR / static
```

for static files.

---

## 17. Load Static Files in the Template

Now open:

```text
WelcomeProject/templates/hello.html
```

At the very top, add:

```django
{% load static %}
```

Then add the CSS file inside `<head>`:

```html
<link rel="stylesheet" href="{% static 'css/style.css' %}">
```

The complete file becomes:

```html
{% load static %}

<!DOCTYPE html>
<html>
<head>
    <title>Welcome Project</title>

    <link rel="stylesheet" href="{% static 'css/style.css' %}">
</head>

<body>

    <h1>HELLO RAM</h1>

</body>
</html>
```

---

## 18. Understand `{% load static %}`

This line:

```django
{% load static %}
```

loads Django's static template tag.

It allows us to use:

```django
{% static 'css/style.css' %}
```

---

## 19. Understand `{% static %}`

This:

```django
{% static 'css/style.css' %}
```

tells Django to generate the correct URL for:

```text
static/css/style.css
```

Instead of manually writing:

```html
<link rel="stylesheet" href="/static/css/style.css">
```

we use:

```html
<link rel="stylesheet" href="{% static 'css/style.css' %}">
```

This is the recommended Django template approach.
