# Django Project No. 0014 — Django CRUD Operations

## 🎯 Project Name

**Student Management System — CRUD Operations**

---

# 🎯 Project Objective

In this project, we will learn **CRUD operations** in Django using buttons on a webpage.

CRUD means:

```text
C → Create
R → Read
U → Update
D → Delete
```

We will create a simple **Student Management System** where the user can click buttons such as:

```text
[ Add Student ]

[ View ]  [ Edit ]  [ Delete ]
```

The user does **not need to type the CRUD URLs manually**.

The buttons will take the user to the correct Django view.

---

# 🧠 What is CRUD?

CRUD represents the four basic operations performed on database data.

```text
Create → Add new student
Read   → View student data
Update → Edit student data
Delete → Remove student data
```

# 📌 Step 12: Create CRUD Views

Open:

```text
students/views.py
```

Add:

```python
from django.shortcuts import (
    render,
    redirect,
    get_object_or_404
)

from .models import Student


# READ

def student_list(request):

    students = Student.objects.all()

    return render(
        request,
        'students/student_list.html',
        {
            'students': students
        }
    )


# CREATE

def student_create(request):

    if request.method == 'POST':

        name = request.POST.get('name')

        age = request.POST.get('age')

        course = request.POST.get('course')

        Student.objects.create(
            name=name,
            age=age,
            course=course
        )

        return redirect('student_list')

    return render(
        request,
        'students/student_form.html'
    )


# READ ONE STUDENT

def student_detail(request, id):

    student = get_object_or_404(
        Student,
        id=id
    )

    return render(
        request,
        'students/student_detail.html',
        {
            'student': student
        }
    )


# UPDATE

def student_update(request, id):

    student = get_object_or_404(
        Student,
        id=id
    )

    if request.method == 'POST':

        student.name = request.POST.get('name')

        student.age = request.POST.get('age')

        student.course = request.POST.get('course')

        student.save()

        return redirect('student_list')

    return render(
        request,
        'students/student_form.html',
        {
            'student': student
        }
    )


# DELETE

def student_delete(request, id):

    student = get_object_or_404(
        Student,
        id=id
    )

    student.delete()

    return redirect('student_list')
```

# 🧠 Why Use `{% url %}`?

Instead of writing:

```html
<a href="/edit/5/">
```

we use:

```django
<a href="{% url 'student_update' student.id %}">
```

This is better because Django generates the URL from the URL name.

If we later change:

```python
path(
    'edit/<int:id>/',
    views.student_update,
    name='student_update'
)
```

to:

```python
path(
    'student-edit/<int:id>/',
    views.student_update,
    name='student_update'
)
```

the template does not need to change.

It still uses:

```django
{% url 'student_update' student.id %}
```

---

# 🧠 Important Concept

The button does not directly call the Python function.

The flow is:

```text
Button
  ↓
{% url %}
  ↓
Django URL
  ↓
View Function
  ↓
Model / Database
```

For example:

```django
{% url 'student_update' student.id %}
```

generates a URL.

That URL is connected to:

```python
student_update()
```

through `urls.py`.
