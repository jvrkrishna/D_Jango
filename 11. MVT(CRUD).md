# 📌 Step 12: Create Views

Open:

```text
students/views.py
```

Add:

```python
from django.shortcuts import render, redirect, get_object_or_404
from .models import Student


# READ

def student_list(request):

    students = Student.objects.all()

    return render(
        request,
        'students/student_list.html',
        {
            'students': students
        }
    )


# CREATE

def student_create(request):

    if request.method == 'POST':

        name = request.POST.get('name')

        age = request.POST.get('age')

        course = request.POST.get('course')

        Student.objects.create(
            name=name,
            age=age,
            course=course
        )

        return redirect('student_list')


    return render(
        request,
        'students/student_form.html'
    )


# UPDATE

def student_update(request, id):

    student = get_object_or_404(
        Student,
        id=id
    )

    if request.method == 'POST':

        student.name = request.POST.get('name')

        student.age = request.POST.get('age')

        student.course = request.POST.get('course')

        student.save()

        return redirect('student_list')


    return render(
        request,
        'students/student_form.html',
        {
            'student': student
        }
    )


# DELETE

def student_delete(request, id):

    student = get_object_or_404(
        Student,
        id=id
    )

    student.delete()

    return redirect('student_list')
```

# 🧠 Understanding the CRUD Views

```text

      ↓

      ↓

      ↓
```

# 1️⃣ READ — Display Students

```python
students = Student.objects.all()
```

This gets all students from the database.

Then:

```python
return render(
    request,
    'students/student_list.html',
    {
        'students': students
    }
)
```

sends the students to the template.

---

# 2️⃣ CREATE — Add Student

First we check:

```python
if request.method == 'POST':
```

Then we get values from the HTML form:

```python
name = request.POST.get('name')

age = request.POST.get('age')

course = request.POST.get('course')
```

Then create a database record:

```python
Student.objects.create(
    name=name,
    age=age,
    course=course
)
```

After creating the student:

```python
return redirect('student_list')
```

takes the user back to the student list.

---

# 3️⃣ UPDATE — Edit Student

First we find the student:

```python
student = get_object_or_404(
    Student,
    id=id
)
```

Then we change the values:

```python
student.name = request.POST.get('name')

student.age = request.POST.get('age')

student.course = request.POST.get('course')
```

Then:

```python
student.save()
```

saves the changes to the database.

---

# 4️⃣ DELETE — Remove Student

First:

```python
student = get_object_or_404(
    Student,
    id=id
)
```

finds the student.

Then:

```python
student.delete()
```

removes the student from the database.

---

# 🧠 What is `get_object_or_404()`?

We use:

```python
get_object_or_404(Student, id=id)
```

to find a specific student.

If the student exists:

```text
Student object
```

is returned.

If the student does not exist:

```text
404 Page Not Found
```

is returned.

This is useful when working with URLs such as:

```text
/edit/5/
```

or:

```text
/delete/5/
```

# 🧠 Why Do We Use `{% csrf_token %}`?

Inside a POST form, Django uses:

```django
{% csrf_token %}
```

for CSRF protection.

So our form contains:

```html
<form method="POST">

    {% csrf_token %}

```

This should be included in Django POST forms.
