# 🧠 What Are DTL Template Tags?

Django Template Tags are written using:

```text
{% %}
```

Template tags tell Django:

> **"Do something inside this HTML template."**

For example:

```django
{% if marks >= 50 %}
```

means:

> If the student's marks are greater than or equal to 50, execute the HTML inside this condition.


---
We will learn these four important tags:

```text
1. {% if %}
2. {% for %}
3. {% url %}
4. {% extends %}
```

---

# 🖼️ DTL Template Tag Flow

```text
views.py
   ↓
Prepare Data
   ↓
Context
   ↓
HTML Template
   ↓
{% if %}
{% for %}
{% url %}
{% extends %}
   ↓
Final HTML
   ↓
Browser
```

# 1️⃣ `{% if %}` Template Tag

## 🎯 Purpose

The `{% if %}` tag is used to make a decision inside a template.

Simple meaning:

> **If something is true, display this HTML.**

---

# 📌 Example

Suppose the student has:

```text
marks = 85
```

We want:

```text
Marks >= 50 → PASS
Marks < 50  → FAIL
```

---

## `student.html`

Create:

```text
App1/templates/App1/student.html
```

Add:

```html
<!DOCTYPE html>

<html>

<head>

    <title>Student Result</title>

</head>

<body>

    <h1>🎓 Student Result</h1>

    <h2>Name: {{ name }}</h2>

    <h2>Marks: {{ marks }}</h2>


    {% if marks >= 50 %}

        <h2>✅ Result: PASS</h2>

    {% else %}

        <h2>❌ Result: FAIL</h2>

    {% endif %}

</body>

</html>
```

---

# 🧠 Understanding `{% if %}`

The syntax is:

```django
{% if condition %}

    HTML

{% endif %}
```

Example:

```django
{% if marks >= 50 %}

    <h2>PASS</h2>

{% endif %}
```

Django checks:

```text
marks >= 50
```

If true:

```text
PASS
```

is displayed.

---

# 📌 `{% else %}`

We can also use:

```django
{% else %}
```

Complete structure:

```django
{% if condition %}

    HTML if TRUE

{% else %}

    HTML if FALSE

{% endif %}
```

---

# 📌 `{% elif %}`

We can check multiple conditions.

```html
{% if marks >= 90 %}

    <h2>Grade: A+</h2>

{% elif marks >= 80 %}

    <h2>Grade: A</h2>

{% elif marks >= 70 %}

    <h2>Grade: B</h2>

{% elif marks >= 50 %}

    <h2>Grade: C</h2>

{% else %}

    <h2>Grade: F</h2>

{% endif %}
```

If:

```text
marks = 85
```

Output:

```text
Grade: A
```

---

# 🧠 Student-Friendly Explanation

Tell students:

> `{% if %}` works like a decision.

For example:

```text
Marks = 85
     ↓
Is 85 >= 50?
     ↓
YES
     ↓
Show PASS
```

# 2️⃣ `{% for %}` Template Tag

## 🎯 Purpose

The `{% for %}` tag is used to repeat HTML for every item in a list.

Simple meaning:

> **Take one item at a time and display it.**

---

# 📌 Example

Our view contains:

```python
student_list = [
    'Rahul',
    'Priya',
    'Arun',
    'Sneha',
]
```

We send it to the template:

```python
context = {
    'students': student_list
}
```

---

# 📌 `students.html`

Create:

```text
App1/templates/App1/students.html
```

Add:

```html
<!DOCTYPE html>

<html>

<head>

    <title>Students</title>

</head>

<body>

    <h1>🎓 Student List</h1>

    <ul>

        {% for student in students %}

            <li>
                {{ student }}
            </li>

        {% endfor %}

    </ul>

</body>

</html>
```

---

# 🧠 Understanding `{% for %}`

Syntax:

```django
{% for variable in list %}

    HTML

{% endfor %}
```

Here:

```django
{% for student in students %}
```

means:

> Take every student from the `students` list one by one.

The first time:

```text
student = Rahul
```

The second time:

```text
student = Priya
```

The third time:

```text
student = Arun
```

The fourth time:

```text
student = Sneha
```

---

# 📊 Loop Flow

```text
students

    ↓

Rahul
    ↓
Display Rahul

    ↓

Priya
    ↓
Display Priya

    ↓

Arun
    ↓
Display Arun

    ↓

Sneha
    ↓
Display Sneha
```

---

# 📌 Beautiful Student List Example

```html
<!DOCTYPE html>

<html>

<head>

    <title>Student List</title>

    <style>

        body {
            font-family: Arial;
            background: #f4f7fb;
        }

        .container {
            width: 500px;
            margin: 50px auto;
        }

        .student {
            background: white;
            padding: 15px;
            margin: 10px;
            border-radius: 10px;
        }

    </style>

</head>

<body>

<div class="container">

    <h1>🎓 Students</h1>

    {% for student in students %}

        <div class="student">

            👤 {{ student }}

        </div>

    {% endfor %}

</div>

</body>

</html>
```

---

# 📌 `forloop.counter`

Django provides useful information about the current loop.

Example:

```html
{% for student in students %}

    <p>
        {{ forloop.counter }}.
        {{ student }}
    </p>

{% endfor %}
```

Output:

```text
1. Rahul
2. Priya
3. Arun
4. Sneha
```

---

# 📌 `forloop.first`

Checks whether this is the first item.

```django
{% if forloop.first %}

    <strong>First Student</strong>

{% endif %}
```

---

# 📌 `forloop.last`

Checks whether this is the last item.

```django
{% if forloop.last %}

    <strong>Last Student</strong>

{% endif %}
```

# 3️⃣ `{% url %}` Template Tag

## 🎯 Purpose

The `{% url %}` tag is used to generate URLs from URL names.

Simple meaning:

> **Instead of writing URLs manually, Django creates the URL for us using the URL name.**

---

# 📌 Why Do We Need `{% url %}`?

Suppose our URL is:

```text
/App1/student/
```

We could write:

```html
<a href="/App1/student/">
    Student
</a>
```

But this is not the best approach.

If the URL changes later, we need to change it in many HTML files.

Instead, we give the URL a name:

```python
path(
    'student/',
    views.student,
    name='student'
)
```

Then inside the template:

```django
{% url 'student' %}
```

Django generates:

```text
/App1/student/
```

---

# 📌 Example

Our `urls.py`:

```python
path(
    'student/',
    views.student,
    name='student'
)
```

Our template:

```html
<a href="{% url 'student' %}">
    Student Profile
</a>
```

Django generates the correct URL.

---

# 🧠 Student-Friendly Explanation

Think of:

```text
name='student'
```

as a nickname.

Instead of remembering the complete address:

```text
/App1/student/
```

we tell Django:

```text
student
```

Django knows the actual URL.

So:

```django
{% url 'student' %}
```

means:

> **Django, give me the URL whose name is `student`.**

---

# 📌 Complete Navigation Example

Modify `home.html`:

```html
<!DOCTYPE html>

<html>

<head>

    <title>Home</title>

</head>

<body>

    <h1>🏠 CampusQuest Home</h1>

    <h2>Navigation</h2>

    <a href="{% url 'home' %}">
        Home
    </a>

    <br><br>

    <a href="{% url 'student' %}">
        Student Profile
    </a>

    <br><br>

    <a href="{% url 'students' %}">
        Student List
    </a>

    <br><br>

    <a href="{% url 'results' %}">
        Results
    </a>

</body>

</html>
```

---

# 📊 `{% url %}` Flow

```text
{% url 'student' %}
        ↓
Django searches urls.py
        ↓
name='student'
        ↓
Finds:
'student/'
        ↓
Creates:
 /App1/student/
```

---

# 📌 `{% url %}` With Parameters

Suppose we have:

```python
path(
    'student/<int:id>/',
    views.student,
    name='student'
)
```

Then we can write:

```django
{% url 'student' 10 %}
```

Django generates:

```text
/App1/student/10/
```

# 4️⃣ `{% extends %}` Template Tag

## 🎯 Purpose

The `{% extends %}` tag is used for **template inheritance**.

Simple meaning:

> **Create one common HTML template and reuse it in other templates.**

---

# 🧠 Why Do We Need Template Inheritance?

Imagine we have 20 pages.

Every page contains:

```text
Header
Navigation
Footer
```

If we write the same HTML in all 20 pages, we get repeated code.

Instead, create:

```text
base.html
```

and put common HTML there.

Then other pages can reuse it.

---

# 📌 Create `base.html`

Create:

```text
App1/templates/App1/base.html
```

Add:

```html
<!DOCTYPE html>

<html>

<head>

    <title>

        {% block title %}

            CampusQuest

        {% endblock %}

    </title>

</head>

<body>

    <header>

        <h1>🎓 CampusQuest</h1>

    </header>


    <nav>

        <a href="{% url 'home' %}">
            Home
        </a>

        |

        <a href="{% url 'student' %}">
            Student
        </a>

        |

        <a href="{% url 'students' %}">
            Students
        </a>

        |

        <a href="{% url 'results' %}">
            Results
        </a>

    </nav>


    <hr>


    <main>

        {% block content %}

        {% endblock %}

    </main>


    <hr>


    <footer>

        <p>© CampusQuest</p>

    </footer>

</body>

</html>
```

---

# 🧠 What Is `{% block %}`?

We have:

```django
{% block content %}

{% endblock %}
```

This creates an area where child templates can put their own content.

Think of it like an empty box:

```text
┌─────────────────────────────┐
│ Header                      │
├─────────────────────────────┤
│ Navigation                  │
├─────────────────────────────┤
│                             │
│      CONTENT GOES HERE      │
│                             │
├─────────────────────────────┤
│ Footer                      │
└─────────────────────────────┘
```

The child template fills:

```text
CONTENT GOES HERE
```

---

# 📌 Create `home.html`

Create:

```text
App1/templates/App1/home.html
```

Add:

```django
{% extends 'App1/base.html' %}


{% block title %}

    Home Page

{% endblock %}


{% block content %}

    <h2>🏠 Welcome to CampusQuest</h2>

    <p>
        This is the home page.
    </p>

{% endblock %}
```

---

# 🧠 Understanding `{% extends %}`

This line:

```django
{% extends 'App1/base.html' %}
```

means:

> Use `base.html` as the parent template.

Then:

```django
{% block title %}
```

changes the title section.

And:

```django
{% block content %}
```

adds the page-specific content.

---

# 📊 Template Inheritance Flow

```text
                 base.html
                    │
        ┌───────────┴───────────┐
        ↓                       ↓
     home.html             student.html
        │                       │
        ↓                       ↓
   Home Content           Student Content
        │                       │
        └───────────┬───────────┘
                    ↓
             Complete HTML
```
