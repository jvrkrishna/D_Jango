# Django Project No. 0001 — WelcomeProject

The project will eventually display:

**Hello, John**

and demonstrate serving an image from the `static` folder.

---

## 1. Daily Common Setup

Open Command Prompt and run:

```cmd
cd Desktop

mkdir CampusQuest

cd CampusQuest

python -m venv venv

venv\Scripts\activate

python -m pip install --upgrade pip

notepad requirements.txt
```

Add this to `requirements.txt`:

```text
Django
djangorestframework
mysqlclient
python-dotenv
```

Install the dependencies:

```cmd
python -m pip install -r requirements.txt
```

---

## 2. Check Django Installation

Run:

```bash
django-admin --version
```

If Django is installed correctly, its version number will be displayed.

---

## 3. Create the Django Project

Run:

```bash
django-admin startproject WelcomeProject
```

This creates a Django project named **WelcomeProject**.

The initial structure is approximately:

```text
WelcomeProject/
│
├── manage.py
│
└── WelcomeProject/
    ├── __init__.py
    ├── settings.py
    ├── urls.py
    ├── asgi.py
    └── wsgi.py
```

### Important Files

| File          | Purpose                              |
| ------------- | ------------------------------------ |
| `manage.py`   | Runs Django project commands         |
| `settings.py` | Project configuration                |
| `urls.py`     | URL patterns                         |
| `asgi.py`     | ASGI deployment                      |
| `wsgi.py`     | WSGI deployment                      |
| `__init__.py` | Makes the directory a Python package |

### Easy Way to Remember

Think of a Django project as a **house**:

* `settings.py` → House settings
* `urls.py` → Directions/address system
* `views.py` → Person deciding the response
* `templates` → Pages shown to visitors
* `static` → Images, CSS, JavaScript, etc.

## 4. Enter the Project Folder

Run:

```bash
cd WelcomeProject
```

You should now be inside:

```text
C:\Users\Username\Desktop\CampusQuest\WelcomeProject>
```

Now Django commands such as this can be executed:

```bash
python manage.py runserver
```

On Windows, you can also use:

```bash
py manage.py runserver
```

---

## 5. Start the Development Server

Run:

```bash
py manage.py runserver
```

Django will start the development server.

You should see something similar to:

```text
Watching for file changes with StatReloader
Performing system checks...

System check identified no issues (0 silenced).

Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.
```

The important line is:

```text
Starting development server at http://127.0.0.1:8000/
```

This means the Django development server is running successfully.

---

## 6. Open Django in the Browser

Open your web browser.

Enter:

```text
http://127.0.0.1:8000/
```

You can also use:

```text
http://localhost:8000/
```

Django should display its default **Congratulations** page.

This confirms that the Django project was created successfully and the development server is working.

### What Happened?

The flow is:

```text
Browser
   ↓
http://127.0.0.1:8000/
   ↓
Django Development Server
   ↓
WelcomeProject
   ↓
Django's default URL configuration
   ↓
Default Django Page
   ↓
Browser
```

At this stage, we have **not yet created a view or changed the URL configuration**, so Django shows its default welcome page.

## 7. Stop the Development Server

When you are finished testing the project, go back to Command Prompt.

Stop the server using:

```text
CTRL + C
```

The development server will stop.

You should return to the command prompt:

```text
C:\Users\Username\Desktop\CampusQuest\WelcomeProject>
```

---

## 8. Deactivate the Virtual Environment

If the virtual environment is still active, run:

```bash
deactivate
```

The `(venv)` prefix should disappear from the command prompt.

Before:

```text
(venv) C:\Users\Username\Desktop\CampusQuest\WelcomeProject>
```

After:

```text
C:\Users\Username\Desktop\CampusQuest\WelcomeProject>
```

This means the virtual environment has been deactivated.

---

## 9. Remove the Virtual Environment

Go back to the `CampusQuest` folder:

```cmd
cd ..
```

You should now be at:

```text
C:\Users\Username\Desktop\CampusQuest>
```

Remove the virtual environment:

```cmd
rmdir /s /q venv
```

This permanently removes the `venv` folder.

### Important

The `venv` folder contains the installed Python packages for this project.

Removing it **does not remove the Django project**.

The following files remain:

```text
CampusQuest/
│
├── requirements.txt
│
└── WelcomeProject/
    ├── manage.py
    └── WelcomeProject/
        ├── __init__.py
        ├── settings.py
        ├── urls.py
        ├── asgi.py
        └── wsgi.py
```

If you want to work on the project again later, you can create a new virtual environment and reinstall the packages from `requirements.txt`.
