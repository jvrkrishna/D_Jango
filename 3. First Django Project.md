# Django Project No. 0001 — WelcomeProject

## 1. Daily Common Setup

Open **Command Prompt** and run:

```cmd
cd Desktop
mkdir CampusQuest
cd CampusQuest
python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
notepad requirements.txt
```

Add the following to `requirements.txt`:

```text
Django
djangorestframework
mysqlclient
python-dotenv
```

Save and close the file.

Install the dependencies:

```cmd
python -m pip install -r requirements.txt
```

---

## 2. Check Django Installation

Run:

```cmd
django-admin --version
```

If Django is installed correctly, its version number will be displayed.

---

## 3. Create the Django Project

Run:

```cmd
django-admin startproject WelcomeProject
```

This creates a Django project named **WelcomeProject**.

The structure will look approximately like this:

```text
CampusQuest/
│
├── requirements.txt
│
└── WelcomeProject/
    ├── manage.py
    │
    └── WelcomeProject/
        ├── __init__.py
        ├── settings.py
        ├── urls.py
        ├── asgi.py
        └── wsgi.py
```

### Important Files

| File | Purpose |
|---|---|
| `manage.py` | Runs Django project commands |
| `settings.py` | Project configuration |
| `urls.py` | URL patterns |
| `asgi.py` | ASGI deployment |
| `wsgi.py` | WSGI deployment |
| `__init__.py` | Makes the directory a Python package |

You do not need to memorize these files at this stage.

The most important file for now is:

```text
manage.py
```

You will use it to run Django commands.

---

## 4. Enter the Project Folder

Run:

```cmd
cd WelcomeProject
```

You should now be inside:

```text
C:\Users\Username\Desktop\CampusQuest\WelcomeProject>
```

You can now run Django commands such as:

```cmd
python manage.py runserver
```

---

## 5. Start the Development Server

Run:

```cmd
python manage.py runserver
```

If everything is working correctly, you should see something similar to:

```text
Watching for file changes with StatReloader
Performing system checks...

System check identified no issues (0 silenced).

Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.
```

The important line is:

```text
Starting development server at http://127.0.0.1:8000/
```

This means the Django development server is running successfully.

---

## 6. Open Django in the Browser

Open your web browser and enter:

```text
http://127.0.0.1:8000/
```

You can also use:

```text
http://localhost:8000/
```

Django should display its default **Congratulations** page.

This confirms that:

- Django is installed correctly.
- The Django project was created successfully.
- The development server is running.
- Django can respond to a browser request.

### What Happened?

The request flow is:

```text
Browser
   ↓
http://127.0.0.1:8000/
   ↓
Django Development Server
   ↓
WelcomeProject
   ↓
Django's default URL configuration
   ↓
Default Django Page
   ↓
Browser
```

At this stage, we have **not created our own view or changed the URL configuration**.

Therefore, Django displays its default welcome page.

When you finish testing, return to Command Prompt.

Stop the server by pressing:

```text
CTRL + C
```

The server will stop.

You should return to:

```text
C:\Users\Username\Desktop\CampusQuest\WelcomeProject>
```

## 8. Deactivate the Virtual Environment

If the virtual environment is active, run:

```cmd
deactivate
```

Before:

```text
(venv) C:\Users\Username\Desktop\CampusQuest\WelcomeProject>
```

After:

```text
C:\Users\Username\Desktop\CampusQuest\WelcomeProject>
```

When `(venv)` disappears, the virtual environment has been deactivated.

---

## 9. Remove the Virtual Environment

> **Note:** You normally do not need to delete the virtual environment after every session. You can keep it and simply deactivate it when finished. Delete it only when you want to recreate the environment from scratch.

If you specifically want to remove it, first go back to the `CampusQuest` folder:

```cmd
cd ..
```

You should now be at:

```text
C:\Users\Username\Desktop\CampusQuest>
```

Remove the virtual environment:

```cmd
rmdir /s /q venv
```

This deletes only the `venv` folder.

### Important

Deleting `venv` **does not delete the Django project**.

The `venv` folder contains the Python virtual environment and installed packages.

Your project files remain:

```text
CampusQuest/
│
├── requirements.txt
│
└── WelcomeProject/
    ├── manage.py
    │
    └── WelcomeProject/
        ├── __init__.py
        ├── settings.py
        ├── urls.py
        ├── asgi.py
        └── wsgi.py
```

If you want to work on the project again later, create a new virtual environment and reinstall the packages:

```cmd
python -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
```
