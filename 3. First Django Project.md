# Django Project No. 0001 — WelcomeProject

## 🎯 Objective

Learn the basic structure of a Django project **without creating a separate Django app**.

The project will eventually display:

**Hello, John**

and demonstrate serving an image from the `static` folder.

---

## 1. Daily Common Setup

Open Command Prompt and run:

```cmd
cd Desktop

cd CampusQuest

python -m venv venv
venv\Scripts\activate

python -m pip install --upgrade pip

```

Add this to `requirements.txt`:


## 3. Create the Django Project

Run:

```bash
django-admin startproject WelcomeProject
```

This creates a Django project named **WelcomeProject**.

The initial structure is approximately:

```text
WelcomeProject/
│
├── manage.py
│
└── WelcomeProject/
    ├── __init__.py
    ├── settings.py
    ├── urls.py
    ├── asgi.py
    └── wsgi.py
```

### Important Files

| File | Purpose |
|---|---|
| `manage.py` | Runs Django project commands |
| `settings.py` | Project configuration |
| `urls.py` | URL patterns |
| `asgi.py` | ASGI deployment |
| `wsgi.py` | WSGI deployment |
| `__init__.py` | Makes the directory a Python package |

### Easy Way to Remember

Think of a Django project as a **house**:

- `settings.py` → House settings
- `urls.py` → Directions/address system
- `views.py` → Person deciding the response
- `templates` → Pages shown to visitors
- `static` → Images, CSS, JavaScript, etc.

## 5. Create `templates` and `static` Folders

At the project level, create:

```text
WelcomeProject/
│
├── manage.py
├── templates/
├── static/
│
└── WelcomeProject/
    ├── settings.py
    ├── urls.py
    └── ...
```

The `templates` folder will contain HTML files.

The `static` folder will contain static resources such as:

- Images
- CSS
- JavaScript

For example:

```text
templates/
└── t1.html
```

and:

```text
static/
└── logo.png
```

---

## 6. Configure the Templates Folder

Open:

```text
WelcomeProject/WelcomeProject/settings.py
```

Find:

```python
'DIRS': [],
```

For a modern Django project using `pathlib`, change it to:

```python
'DIRS': [BASE_DIR / 'templates'],
```

### Why?

This tells Django:

> Our HTML template files are inside the `templates` folder.

Therefore, when we later use:

```python
return render(request, 't1.html')
```

Django knows where to find `t1.html`.

### What is `BASE_DIR`?

`BASE_DIR` represents the main project directory.

Conceptually:

```text
BASE_DIR
   ↓
WelcomeProject/
├── templates/
├── static/
└── manage.py
```

---

## 7. Configure the Static Folder

At the bottom of `settings.py`, add:

```python
STATICFILES_DIRS = [
    BASE_DIR / 'static'
]
```

This tells Django:

> Our additional static files are inside the `static` folder.

For example:

```text
static/
└── logo.png
```

Django can then locate `logo.png`.
