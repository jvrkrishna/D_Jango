# 5. Form Field Options

Django fields accept many useful options.

| Option | Purpose | Example |
|---|---|---|
| `required` | Makes the field required or optional | `required=True` |
| `label` | Sets the label displayed to the user | `label="Student Name"` |
| `initial` | Provides an initial/default value | `initial="John"` |
| `help_text` | Displays additional information or instructions | `help_text="Enter your full name."` |
| `disabled` | Prevents the user from editing the field | `disabled=True` |
| `validators` | Adds custom validation functions | `validators=[validate_name]` |
| `error_messages` | Customizes Django's default error messages | `error_messages={"required": "Please enter your name."}` |
| `widget` | Controls how the field is represented in HTML | `widget=forms.TextInput()` |

---

## Quick Example
```
name = forms.CharField(
    required=True,
    label="Student Name",
    initial="John",
    help_text="Enter your full name.",
    disabled=False,
    validators=[],
    error_messages={
        "required": "Please enter your name."
    },
    widget=forms.TextInput()
)
```

# 6. Widgets

## What is a Widget?

A **widget** controls how a Django Form field is displayed as HTML.

Think of it like this:

```
Field
  ↓
What type of data is expected?
  ↓
Widget
  ↓
How should the field appear in HTML?
```

For example:

```
name = forms.CharField()
```

The field expects text.

A widget determines how that text field is displayed.

---

## Field vs Widget

| FieldWidget                 |                               |
| --------------------------- | ----------------------------- |
| Handles data and validation | Controls HTML representation  |
| Defines expected data       | Defines how the input appears |
| Example: `CharField`        | Example: `TextInput`          |
| Example: `EmailField`       | Example: `EmailInput`         |

Example:

```
email = forms.EmailField(
    widget=forms.EmailInput()
)
```

Here:

```
EmailField → data/validation
EmailInput → HTML representation
```

---

We can customize the generated HTML using `widget`.

For example:

```
name = forms.CharField(
    widget=forms.TextInput(
        attrs={
            "class": "form-control",
            "placeholder": "Enter your name"
        }
    )
)
```
