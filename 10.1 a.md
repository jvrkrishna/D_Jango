## 🎯 Project Goal

In this project, we will learn the complete Django flow:

```text
Models → Views → Templates
```

We will learn how to:

- Create a Django project and application
- Create a model
- Store blog post data in the database
- Run migrations
- Register the model in Admin
- Create a superuser
- Fetch database data in a view
- Send model data to a template
- Display database data using DTL
- Filter posts by author
- Configure application-level URLs
- Create a common `base.html`
- Create app-level Create, Read, Update, Delete options
- Connect CRUD operations with the `Post` model
- Run and test the website

# 👀 Step 11: Create the View

Open:

```text
Sample_Project/myapp/views.py
```

Add:

```python
from django.shortcuts import render

from .models import Post


# Show all posts
def myapp_view(request):

    posts = Post.objects.all()

    return render(
        request,
        'myapp/myapp_home.html',
        {
            'posts': posts
        }
    )


# Show only posts by author "RK"
def rk_posts_view(request):

    posts = Post.objects.filter(
        author="RK"
    )

    return render(
        request,
        'myapp/myapp_home.html',
        {
            'posts': posts
        }
    )
```

| Code | Meaning |

# 🛠 Step 17: Create App-Level CRUD Views

Now we will add application-level:

```text
Create
Read
Update
Delete
```

operations for the `Post` model.

Open:

```text
Sample_Project/myapp/views.py
```

Replace the file with:

```python
from django.shortcuts import (
    render,
    redirect,
    get_object_or_404
)

from .models import Post


# ==========================================
# READ - Show all posts
# ==========================================

def myapp_view(request):

    posts = Post.objects.all()

    return render(
        request,
        'myapp/myapp_home.html',
        {
            'posts': posts
        }
    )


# ==========================================
# READ - Show only posts by author "RK"
# ==========================================

def rk_posts_view(request):

    posts = Post.objects.filter(
        author="RK"
    )

    return render(
        request,
        'myapp/myapp_home.html',
        {
            'posts': posts
        }
    )


# ==========================================
# CREATE
# ==========================================

def create_post(request):

    if request.method == 'POST':

        title = request.POST.get('title')

        content = request.POST.get('content')

        author = request.POST.get('author')


        Post.objects.create(

            title=title,

            content=content,

            author=author

        )


        return redirect('all_posts')


    return render(
        request,
        'myapp/create_post.html'
    )


# ==========================================
# READ
# ==========================================

def read_posts(request):

    posts = Post.objects.all()


    return render(

        request,

        'myapp/read_posts.html',

        {
            'posts': posts
        }

    )


# ==========================================
# UPDATE - Show all posts
# ==========================================

def update_posts(request):

    posts = Post.objects.all()


    return render(

        request,

        'myapp/update_posts.html',

        {
            'posts': posts
        }

    )


# ==========================================
# UPDATE - Update one post
# ==========================================

def update_post(request, post_id):

    post = get_object_or_404(
        Post,
        id=post_id
    )


    if request.method == 'POST':

        post.title = request.POST.get('title')

        post.content = request.POST.get('content')

        post.author = request.POST.get('author')

        post.save()


        return redirect('update_posts')


    return render(

        request,

        'myapp/update_post.html',

        {
            'post': post
        }

    )


# ==========================================
# DELETE - Show all posts
# ==========================================

def delete_posts(request):

    posts = Post.objects.all()


    return render(

        request,

        'myapp/delete_posts.html',

        {
            'posts': posts
        }

    )


# ==========================================
# DELETE - Delete one post
# ==========================================

def delete_post(request, post_id):

    post = get_object_or_404(
        Post,
        id=post_id
    )


    if request.method == 'POST':

        post.delete()

        return redirect('delete_posts')


    return render(

        request,

        'myapp/delete_post.html',

        {
            'post': post
        }

    )
```

# 🧠 Important Concept: ORM

This code:

```python
Post.objects.all()
```

is Django ORM.

We do not need to write SQL manually.

Instead of writing a SQL query such as:

```sql
SELECT * FROM blog_post;
```

we can use:

```python
Post.objects.all()
```

Django ORM handles the database query.

---

# 📊 `Post.objects.all()`

Means:

```text
Give me all Post objects.
```

---

# 📊 `Post.objects.filter()`

Means:

```text
Give me Post objects

that match this condition.
```

Example:

```python
Post.objects.filter(
    author="RK"
)
```

Means:

```text
Give me posts

where author is RK.
```

# 🧠 Why Use One `base.html`?

Without `base.html`, every template would need to repeat:

```html
<!DOCTYPE html>

<html>

<head>
    ...
</head>

<body>

<header>
    ...
</header>

...

<footer>
    ...
</footer>

</body>

</html>
```

With `base.html`:

```text
base.html
    ↓
Common Header
    ↓
Common Navigation
    ↓
Page Content
    ↓
Common Footer
```

Each page only needs:

```django
{% extends 'base.html' %}
```

and:

```django
{% block content %}

    Page-specific content

{% endblock %}
```
