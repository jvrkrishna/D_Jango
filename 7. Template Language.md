# 🎯 Project Objective

In this project, we will learn **Django Template Language (DTL)** in simple steps.

We will learn how to:

- Create a Django project
- Create a Django application
- Create an HTML template
- Connect a view with a template
- Send data from `views.py` to an HTML template
- Display variables using `{{ }}` 
- Use template tags using `{% %}`
- Use `if` and `else`
- Use `for` loops
- Use filters such as `upper`, `lower`, and `title`
- Write template comments
- Access values using dot notation
- Create a simple student profile page
- Understand template inheritance using `base.html`
- Understand the difference between Python code and DTL

> **Simple definition:**  
> **Django Template Language (DTL) is the language we use inside Django HTML templates to display and control dynamic data.**

Django's template system is designed for presentation rather than arbitrary Python logic. It provides variables, tags, filters, comments, and template inheritance. citeturn0search0

# 🖼️ DTL Request Flow

![DTL Request Flow](dtl_request_flow.png)

The basic idea is:

```text
Browser
   ↓

   ↓

   ↓

   ↓

   ↓

   ↓

```

The view prepares the data, and the template decides how that data should be displayed.

# 🧠 What Is `context`?

The `context` is the data that we send from the view to the template.

Here:

```python

    'age': 21,
    'course': 'Django',
    'city': 'Bangalore',
    'marks': 85,
}
```

We are sending:

```text
name   → Rahul
age    → 21
course → Django
city   → Bangalore
marks  → 85
```

The template can use these values.

# 🧠 The Most Important DTL Syntax: `{{ }}`

When we write:

```html
{{ name }}
```

Django replaces it with the value of `name`.

The view sends:

```python
'name': 'Rahul'
```

The template contains:

```html
{{ name }}
```

The browser receives:

```html
Rahul
```

So:

```text
Python data
     ↓
'name': 'Rahul'
     ↓
{{ name }}
     ↓
Rahul
```

# 🧠 Now Let's Learn the Four Main Parts of DTL

# 1️⃣ Variables

Variables are written using:

```text
{{ variable }}
```

Example:

```html
<h1>Hello {{ name }}</h1>
```

If the view sends:

```python
'name': 'Rahul'
```

The browser displays:

```text
Hello Rahul
```

---

# 📌 More Variable Examples

```html
{{ name }}

{{ age }}

{{ course }}

{{ city }}

{{ marks }}
```

If the context is:

```python
context = {
    'name': 'Rahul',
    'age': 21,
    'course': 'Django',
    'city': 'Bangalore',
    'marks': 85,
}
```

The output becomes:

```text
Rahul
21
Django
Bangalore
85
```

---

# 2️⃣ Template Tags

Template tags are written using:

```text
{% tag %}
```

Tags are used when we need simple logic or template instructions.

For example:

```django
{% if marks >= 50 %}
    Pass
{% else %}
    Fail
{% endif %}
```

Tags do not directly display a variable.

They control what the template does.

---

# 📌 `if` Tag

Example:

```html
{% if marks >= 50 %}

    <h2>✅ Student Passed</h2>

{% else %}

    <h2>❌ Student Failed</h2>

{% endif %}
```

If:

```text
marks = 85
```

the output is:

```text
✅ Student Passed
```

---

# 📌 `if` / `elif` / `else`

Example:

```html
{% if marks >= 90 %}

    <p>Grade: A+</p>

{% elif marks >= 80 %}

    <p>Grade: A</p>

{% elif marks >= 70 %}

    <p>Grade: B</p>

{% elif marks >= 50 %}

    <p>Grade: C</p>

{% else %}

    <p>Grade: F</p>

{% endif %}
```

For:

```text
marks = 85
```

the output is:

```text
Grade: A
```

---

# 3️⃣ `for` Loop

We can display a list of values using:

```django
{% for student in students %}

    ...

{% endfor %}
```

---

# 📌 Example: Student List

Change the view:

```python
from django.shortcuts import render


def students(request):

    student_list = [
        'Rahul',
        'Priya',
        'Arun',
        'Sneha',
    ]

    context = {
        'students': student_list
    }

    return render(
        request,
        'App1/students.html',
        context
    )
```

Template:

```html
<h1>Student List</h1>

<ul>

    {% for student in students %}

        <li>{{ student }}</li>

    {% endfor %}

</ul>
```

Output:

```text
Student List

• Rahul
• Priya
• Arun
• Sneha
```

---

# 🧠 How the `for` Loop Works

Django receives:

```python
students = [
    'Rahul',
    'Priya',
    'Arun',
    'Sneha',
]
```

Then:

```django
{% for student in students %}
```

means:

> Take one student at a time from the `students` list.

Then:

```html
{{ student }}
```

displays the current student.

Finally:

```django
{% endfor %}
```

ends the loop.

# 4️⃣ Filters

Filters modify the value before displaying it.

Syntax:

```text
{{ value|filter }}
```

Django provides built-in filters for common display transformations. citeturn0search0turn0search9



```text

```

---

# 📌 `lower` Filter

```html
{{ name|lower }}
```

Output:

```text
rahul
```

---

# 📌 `title` Filter

```html
{{ course|title }}
```

If:

```text
course = web development
```

Output:

```text

```

---

# 📌 `length` Filter

```html
{{ name|length }}
```

If:

```text
name = Rahul
```

```text

```

---

# 📌 Multiple Filters

Filters can be chained.

Example:

```html
{{ name|lower|title }}
```

If:

```text
name = RAHUL
```

```text

```

---

# 5️⃣ Template Comments

A Django template comment is:

```django
{# This is a comment #}
```

Example:

```html
<h1>Student Profile</h1>

{# This text is only for the developer #}
```

The comment will not appear in the rendered HTML output.

For a multi-line template comment, Django also provides the `comment` tag. citeturn0search0turn0search2

Example:

```django
{% comment %}
This is a
multi-line comment.
{% endcomment %}
```

| DTL Syntax | Purpose | Example |
|---|---|---|
| `{{ }}` | Display value | `{{ name }}` |
| `{% %}` | Template tag / logic | `{% if marks >= 50 %}` |
| `\|` | Apply filter | `{{ name\|upper }}` |
| `{# #}` | Comment | `{# Hello #}` |

# 🔥 Very Important: DTL Is Not Normal Python

Students often make this mistake.

Do **not** think of:

```django
{% if student.marks >= 50 %}
```

as putting Python directly inside HTML.

Django Template Language is its own template language. It provides a limited set of tags, filters, and syntax for presentation; it does not execute arbitrary Python expressions. citeturn0search0

For example, don't write arbitrary Python such as:

```django
{% student.marks + 10 %}
```

Instead, prepare complicated calculations in `views.py` and send the result to the template.

# 📌 Template Inheritance

When a website has many pages, we usually don't want to repeat the same:

```text
Navbar
Header
Footer
CSS
```

on every page.

Django provides template inheritance using:

```django
{% extends %}
```

and:

```django
{% block %}
```

This lets a base template define the common layout and child templates fill in specific sections. citeturn0search0

---

# 📌 Create `base.html`

Create:

```text
App1/templates/App1/base.html
```

Add:

```html
<!DOCTYPE html>

<html>

<head>

    <title>
        {% block title %}
            My Website
        {% endblock %}
    </title>

</head>

<body>

    <header>

        <h1>🎓 CampusQuest</h1>

        <nav>

            <a href="/App1/student/">Student</a>

            <a href="/App1/dashboard/">Dashboard</a>

        </nav>

    </header>


    <main>

        {% block content %}

        {% endblock %}

    </main>


    <footer>

        <p>© CampusQuest</p>

    </footer>

</body>

</html>
```

---

# 📌 Create a Child Template

Create:

```text
App1/templates/App1/home.html
```

Add:

```django
{% extends 'App1/base.html' %}


{% block title %}

    Home

{% endblock %}


{% block content %}

    <h2>Welcome to CampusQuest 🎓</h2>

    <p>This is the home page.</p>

{% endblock %}
```

---

# 🧠 How Template Inheritance Works

Think of:

```text
base.html
```

as the **building**.

It contains:

```text
Header
Navbar
Footer
```

The child page:

```text
home.html
```

only fills the empty room:

```text
{% block content %}
```

So:

```text
base.html
      +
home.html
      ↓
Complete HTML page
```
